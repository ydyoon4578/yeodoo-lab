## 0. 🚨 잣대가 바뀐다 — 이 랩이 안 재던 축이다

어제까지 이 랩이 낸 수는 전부 **절대 위험조정수익(샤프)** 이다. 지수 펀드는 그것으로 안 산다.

| | 랩이 재 온 것 | 지수 펀드가 사는 것 |
|---|---|---|
| 출발 비중 | 동일가중 상위 N종 | **벤치 비중(시총가중)** |
| 목적 | 샤프 | **정보비율 IR = 초과수익 ÷ 추적오차** |
| 제약 | 없음 | 롱온리 · 개별·섹터 능동한도 · 회전 |

**그래서 어제 만든 20~50종 동일가중 판은 애초에 펀드에 못 쓴다** — 추적오차가 8~10%p 다.
`grep` 으로 확인했다: `tech_backtest.py` 에 추적오차·정보비율을 **계산하는 코드가 없다**
(주석에 개념만 나온다). **이 등록이 그 축을 처음 만든다.**

## 1. 규칙 — `x-idxtilt-spx` · `x-idxtilt-ndx`

두 벤치를 **나란히** 돌린다. 다른 «상품» 이지 한 선택의 변형이 아니므로 `nsel` 이 아니다.
🚨 **좋은 쪽만 싣지 않는다.**

```
유니버스   그 달 실제 편입명단 (SPX / NDX · data/index_history.json)     ← PIT
출발 비중   그 달 시총가중 = 벤치마크 그 자체
능동 비중   w(t) = w_bench(t) + λ · tilt(t)
           tilt = 합성점수의 섹터 내 z 를 «벤치 비중가중 평균 0» 으로 맞춘 것
제약       ① 롱온리  w ≥ 0
           ② 개별 능동  |w − w_bench| ≤ 1.0%p
           ③ 섹터 능동  |Σ섹터(w − w_bench)| ≤ 3.0%p
주기       월말 · 비용 왕복 20bp (랩 값)
```

### 1-1. 팩터 셋 — **교과서로 정한다. 성적으로 안 고른다**

| 팩터 | 방향 | 원천 |
|---|---|---|
| 가치 B/M | 높을수록 | Fama·French (1992) |
| 수익성 총이익/총자산 | 높을수록 | Novy-Marx (2013) · **FF5 RMW** |
| 투자 자산성장 | **낮을수록** | Cooper·Gulen·Schill (2008) · **FF5 CMA** |
| 모멘텀 12-1 | 높을수록 | Jegadeesh·Titman (1993) |
| 저변동 60일 | **낮을수록** | Frazzini·Pedersen (2014) |
| 발생액 | **낮을수록** | Sloan (1996) |
| 순주식발행 | **낮을수록** | Pontiff·Woodgate (2008) |

**일곱이다. 하나도 이 랩의 성적을 보고 넣지 않았다.**
🚨 그 증거: **수익성이 들어 있다.** 이 랩은 수익성을 다섯 번 시험해 **다섯 번 다 졌다**
(`x-roe` −0.140 · `x-npm` −0.141 · `x-gpa` −0.089 · `x-ocfp` −0.090 ·
어제 `PUREGP` Δ−0.117). 성적으로 골랐다면 뺐을 것이다. **FF5 의 구성요소라 넣는다.**

⚠ **규모(SMB)는 안 넣는다** — 대형주 지수 안이라 축이 거의 안 선다.

### 1-2. 🚨 BOK 에서 무엇을 가져오고 무엇을 버리나

메모리에 사용자 정정이 남아 있다 — *"완전히 BOK방식을 따르라는게 아니라 좋은게 있으면
참고해라"*, 그리고 2026-08-14 *"8단계를 체크리스트로 삼아 하나씩 이식하려 들지 말 것"*.

| BOK | 이 등록 | 사유 |
|---|---|---|
| ① 200+ 팩터 | **7팩터(교과서)** | 200개가 없다. 55종을 엔진에서 끌면 **채점기 사본**이 생긴다 |
| ② 섹터 내 표준화 | **가져온다** | 랩에 컴포지트의 섹터 내 z 가 없다 |
| ③ 롤링 t 랭킹 + 히스테리시스 | **안 가져온다** | 🚨 7개면 **고를 것이 없다.** 층을 얹으면 자유도만 는다 |
| ④ **ERC · 공분산 · 대각 축소** | **가져온다(진짜 ERC)** | 사용자 지시. 랩에 가중 최적화가 **아예 없다** |
| ⑤ 모멘텀 틸트 · 스타일 캡 | **안 가져온다** | 개별·섹터 능동한도가 그 자리를 대신한다 |
| ⑥ 워크포워드 | **구조상 그렇다** | ERC 공분산이 롤링 48개월 후행이다 |
| ⑦ 비용 왕복 10bp | **왕복 20bp**(랩 값) | 랩 규약이 더 보수적이다 |
| ⑧ 대시보드 | 안 한다 | |

### 1-3. ERC — 진짜로 푼다

```
① 각 팩터 f 의 월별 «스프레드 수익» = 섹터 내 z 상위 5분위 − 하위 5분위 (동일가중)
② 롤링 48개월로 공분산 Σ 를 낸다                      ← t−1 까지만. 선견 없음
③ 대각 축소   Σ* = 0.8·Σ + 0.2·diag(Σ)               ← BOK 의 0.2
④ ERC 를 푼다 — 각 팩터의 위험기여가 같아지도록
       RC_i = w_i (Σ*w)_i  가 전부 같게
   반복법: w_i ← w_i · [ (Σ*w)_i ]^(−1/2) 정규화, 수렴까지 (또는 200회)
   🚨 Spinu CCD 대신 표준 고정점 반복을 쓴다 — 7×7 이라 수렴이 빠르다. 그렇게 적는다.
⑤ 합성점수 = Σ_f  w_f · z_f
```
- **48개월·0.2 축소는 BOK 의 수**다. 결과 보고 안 바꾼다(§7).
- warm 48개월 → **표본 밖 2020-09 ~ 2026-09** (약 73개월).

### 1-4. λ — **고르지 않는다**

정보비율은 틸트 크기에 거의 안 변한다(초과수익과 추적오차가 같이 커진다).
그래서 **λ 를 사전 추적오차 목표 1.0% · 2.0% · 3.0% 에 맞춰 세 벌 다 돌리고 전부 싣는다.**
🚨 **판정은 2.0% 판으로 한다**(지수 강화 펀드의 통상 범위 1~3%의 가운데). **계산 전에 정한다.**
나머지 둘은 **IR 이 크기에 안 변하는지 보는 확인용**이다 — 좋은 쪽을 고르는 데 안 쓴다.

## 4. 실패 조건 (두 벤치에 **각각** 적용)

- **F1 🚨** 판정 구간에서 **IR > 0 이고 t ≥ 1.5** 가 아니면 기각.
  (t 는 월별 초과수익의 t. IR = 연 초과수익 ÷ 연 추적오차)
- **F2 🚨 ERC 의 순값.** ERC 판이 **동일가중(1/7) 판**을 IR 에서 못 넘으면
  「ERC 가 값을 못 냈다」를 판정문 첫 줄에 적는다. ⚠ 기각 조건은 아니다 — 1번은 벤치다.
- **F3 설계 검증.** 실현 추적오차가 목표 2.0% 의 **±1.0%p 안**에 안 들어오면
  「틸트 크기 조절이 안 됐다」고 적는다.
- **F4** 왕복 20bp 뒤 F1 을 유지 못 하면 기각.
- **F5 🚨 제약이 실제로 무는가.** 개별 ±1%p·섹터 ±3%p 에 걸린 비중을 싣는다.
  거의 안 물면 제약이 장식이고, 늘 물면 신호가 아니라 제약이 포트를 정한 것이다.
- **F6** 회전율·능동비중(active share)을 싣는다.
- **F7 🚨 두 벤치를 나란히 싣는다.** 좋은 쪽만 싣지 않는다.
- **F8** 팩터 일곱 중 **자료를 못 내는 종목 비율**을 싣는다. 벤치 시총의 10% 를 넘게
  채점 못 하면 「유니버스를 반쪽만 틸팅했다」를 첫 줄에 적는다.

### 4-1. 예측 — 🚨 **기각 쪽을 예상한다**

- **P1 F1 을 못 넘을 것이다(t < 1.5).** 근거 셋 —
  ① 어제 여섯 등록에서 알파가 하나도 안 나왔다(알파 t 0.27~0.41).
  ② 이 랩 PIT 118종의 **최고 t 가 2.09** 이고 랩 귀무 「최고 t」 중앙이 **2.259** 다.
  ③ 능동 한도를 걸면 신호가 더 눌린다.
- **P2** 추적오차는 목표대로 나온다(F3 통과). 기계적이다.
- **P3 🚨 NDX 쪽이 SPX 쪽보다 IR 이 낮을 것이다.** 100종뿐이라 ±1%p 능동한도가 훨씬 빡빡하고,
  벤치 상위 몇 종목의 비중이 커서 틸트 여지가 작다.
- **P4** ERC 가 동일가중(1/7)과 **큰 차이를 안 낼 것이다**(IR 차이 0.10 미만).
  일곱 팩터의 스프레드가 서로 상관이 높을 것이기 때문이다.
- **P5** 모멘텀과 저변동이 ERC 에서 **가장 낮은 가중**을 받을 것이다(변동이 커서).

## 5. 미리 적어 두는 반론

- **7팩터는 BOK 의 200개에 비해 작다.** BOK 은 MXWO(선진국 전체)이고 여기는 대형주다.
  **같은 수가 나올 이유가 없다** — BOK net 샤프 0.840 을 목표로 삼지 않는다.
- **엔진의 55종을 안 쓴다**(§1-2 ①). 그것을 쓰려면 `xsec_score_at` 을 밖에서 부를 X 를
  다시 지어야 하는데, 그것이 이 저장소가 2026-08-11 에 없앤 **채점기 사본**이다.
  대신 `TB.ttm2`·`TB.asof_fund`·`TB._gross_profit` 같은 **공유 원시함수**로 일곱을 낸다 —
  `pure10.py`·`puregp.py` 가 이미 쓰는 방식이다.
- **생존편향.** PIT 유니버스라 선견은 없지만, 편출 종목의 **재무**가 `data/fx_pit` 에
  얼마나 있는지가 커버리지를 정한다. F8 이 그것을 잰다.
- **월간 격자**다. 실제 펀드는 일간으로 리밸런스 여지가 있다.
- **세금·시장충격 없음.** 왕복 20bp 는 대형주 기준이고 시장충격은 안 문다.

## 6. 이 등록이 답하지 못하는 것

**「이 전략을 실제 펀드에 넣을 수 있는가」에는 답하지 못한다.**
잰 것은 종이 위의 초과수익이고, 실제 운용에는 세금·충격비용·유동성·규제 제약이 더 붙는다.
말할 수 있는 것은 **「벤치 대비 능동 틸트가 이 표본에서 값을 냈는가」** 하나다.

## 7. 안 하는 것

- 🚨 **팩터를 빼거나 더해 다시 돌리는 것.** 일곱은 교과서가 정했다.
- 🚨 **48개월·0.2 축소·능동한도(±1%p·±3%p)를 결과 보고 바꾸는 것.**
- 🚨 **TE 1%/2%/3% 중 좋은 쪽을 판정으로 삼는 것**(§1-4). 판정은 2.0% 다.
- 🚨 **두 벤치 중 좋은 쪽만 싣는 것**(F7).
- 롤링 t 팩터 랭킹·히스테리시스를 얹는 것(§1-2 ③).
- 숏을 허용하는 것 — 펀드는 롱온리다.
- ERC 대신 다른 최적화(최소분산·최대분산화)를 같이 돌려 고르는 것.
