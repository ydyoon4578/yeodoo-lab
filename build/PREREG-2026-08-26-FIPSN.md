# 사전등록 — 프로그인더팬 업종중립 롱숏 · 2026-08-26, 돌리기 전에 확정

사용자 지시(2026-08-26) «업종 중립화한 버전으로 사전등록. 논문을 최대한 따라해서».

## 이번이 네 번째다 — 앞선 셋이 무엇을 했고 왜 죽었나

| 등록 | 축 | 소급 | PIT | 편향 |
|---|---|---|---|---|
| x-fip (08-18) | ID 를 **선택** 축으로 | 초과 +5.90%p · t 1.49 | **t 0.35** · +1.12%p | 5.71%p |
| FIPHOLD (08-24) | ID 를 **보유기간** 축으로 | F3 샤프 1.224 · t 4.18 | F2 **t 0.60** · F3 **t 1.21** | 13.60 / 20.85%p |
| FIPMCF (08-25) | 위 + 시총 하한 | F3 CAGR 29.54 | F3 **t 1.12** | 11.88%p |

셋 다 «소급으로 보면 알파, PIT 으로 재면 아니다» 로 끝났다. 그런데 **셋 다 논문이 주장한
것을 잰 적이 없다.** 그것이 이 등록의 이유다.

## 🚨 앞선 셋의 공통 결함 — 논문은 롱숏인데 랩은 전부 롱온리였다

논문 Table 2 Panel A(6개월 보유, $5 가격필터, 1976~2007 CRSP):

    모멘텀 = 승자 매수 − 패자 매도
      저ID(연속) 8.86%   고ID(이산) 2.91%   차이 **5.95%** (t 5.13)
      FF3 조정 후 차이 6.89% (t 7.01) · 독립정렬로 해도 1.63% → 8.33%

    그 차이를 다리별로 뜯으면
      승자만: 8.38%(고ID) → 11.08%(저ID)   = **+2.70%**
      패자만: 5.47%(고ID) →  2.22%(저ID)   = **+3.25%**  ← 이쪽이 더 크다

🚨 **효과의 절반 이상이 패자 다리에 있다.** x-fip·F2·F3 는 전부 승자 롱온리였으므로
  구조적으로 5.95% 중 2.70% 만 잡을 수 있는 설계였다. «논문이 안 먹힌다» 가 아니라
  **논문의 주장을 아직 안 재 봤다.** 랩은 2026-08-23 NARRATIVE 등록으로 롱숏
  (LONGSHORT_SIDS · 다리별 되정규화 · 총노출 롱100/숏100)을 이미 갖췄다.

## 🚨 그리고 ID 정렬은 업종을 쏠리게 한다 — 등록 전에 쟀다

승자 바스켓(PRET 최상위 5분위 ~103종) 안에서 20종을 뽑을 때 **최대 업종 비중**,
월말 198개:

| 뽑는 방법 | 중앙 | 평균 | 무작위 대비 |
|---|---|---|---|
| 무작위(크기 대조) | 28.6% | 29.1% | — |
| 연속(저 ID) | 31.6% | **33.5%** | **+4.5%p (t 6.23)** |
| 이산(고 ID) | 29.4% | 30.9% | +1.8%p (t 3.24) |
| | | 연속−이산 | **+2.6%p (t 2.83)** |

⚠ **무작위 대조를 반드시 끼웠다.** 103종 → 20종으로 줄이면 크기만으로 집중도가 오르므로,
  같은 크기 무작위 부분집합(월말마다 30회 복원추출)과 견주지 않으면 «ID 가 쏠리게 한다» 를
  말할 수 없다. 실제로 무작위도 29.1% 였다 — 관찰된 33.5% 중 크기 효과가 대부분이다.
  그래도 남는 +4.5%p 는 ID 고유분이고, 연속 쪽이 이산 쪽보다 2.6%p 더 쏠린다.
⚠ 월말 관측은 6개월 보유로 겹치므로 위 t 는 부풀려 있다. 방향과 크기만 근거로 쓰고
  유의성은 근거로 쓰지 않는다.
최근 실례(2026-05·06 월말): 연속 바스켓의 IT 비중이 60% 였고 이산은 35~40% 였다.

즉 «연속정보 종목» 이라 부른 것이 실제로는 «그 시기 잘 나간 업종» 일 수 있다.
논문은 CRSP 전종목(2,301,912 firm-month)이라 이 문제가 희석되지만, 이 랩은 518종이다.

## 규칙 — 넷을 **쌍의 쌍** 으로 등록한다

공통 규약(논문을 그대로 옮긴다):
    형성창 [i−251, i−21] · PRET = 그 창 누적수익 · 형성과 보유 사이 1개월(21거래일) 건너뜀
    ID = sign(PRET) × (%neg − %pos)     ← build/tech_backtest.py 의 info_disc, 안 고친다
    매 월말 PRET **5분위** → 그 안에서 ID **5분위** (순차 이중정렬, 논문 Panel A 와 같다)
    롱 = PRET 최상위 5분위 ∩ 해당 ID 분위 · 숏 = PRET 최하위 5분위 ∩ 해당 ID 분위
    다리 안 동일가중 · 보유 126거래일(6개월) · 대조군은 무위험(현금)

**G1 `x-fipq-cont` — 연속정보 롱숏 (업종 비중립)**   ID 최하위 5분위
**G2 `x-fipq-disc` — 이산정보 롱숏 (거울)**          ID 최상위 5분위
**G3 `x-fipq-cont-sn` — 연속정보 롱숏 · 업종중립**
**G4 `x-fipq-disc-sn` — 이산정보 롱숏 · 업종중립 (거울)**

업종중립의 정의 — **ID 축에만 건다.**
    각 PRET 5분위 안에서, 종목의 ID 에서 «같은 분위·같은 섹터» 평균 ID 를 뺀다.
    그 잔차로 ID 5분위를 만든다. 섹터 칸에 3종 미만이면 그 종목은 뺀다(중립이 정의 안 됨).
⚠ PRET 축은 건드리지 않는다. 묻는 것이 «ID 효과가 업종의 다른 이름인가» 이므로,
  모멘텀까지 중립화하면 무엇이 바뀌었는지 못 가린다. 한 번에 한 축만 바꾼다.
⚠ 섹터를 모르는 종목은 뺀다. «기타» 칸을 만들면 그 칸이 중립의 예외가 된다
  (pick_sector_neutral 의 기존 규약과 같다).

🚨 **넷을 다 등록해야 답이 나온다.** 이 등록이 재는 것은 규칙 하나의 성적이 아니라

        (G1 − G2)  vs  (G3 − G4)

    이다. G3−G4 가 G1−G2 만큼 남으면 ID 효과는 업종이 아니다. 크게 줄면 업종이었다.
    거울(G2·G4) 없이 연속만 등록하면 «업종중립이 성적을 낮췄다» 와 «ID 효과가 원래
    업종이었다» 를 영원히 못 가른다. FIPHOLD 등록에서 F3 를 넣은 것과 같은 이유다.

## 미리 적어 두는 실패 조건

- **PIT 로 재서 G3−G4 의 t 가 1 미만이면 그것으로 끝이다.** 앞선 세 등록이 전부 PIT 에서
  죽었고 이 등록은 같은 자료·같은 유니버스를 쓴다. 소급이 좋아도 PIT 이 답이다.
- G3−G4 가 G1−G2 의 절반 미만이면 **ID 효과의 절반 이상이 업종이었다** 고 적는다.
  그때는 «업종중립 FIP» 를 배포 후보로 올리지 않는다. 남은 절반이 유의해도 마찬가지다 —
  그건 이 등록이 묻지 않은 질문이다.
- G1−G2 자체가 소급에서도 논문 방향(연속 > 이산)이 아니면 거기서 멈춘다. 중립화는
  방향이 맞는 것을 정제하는 도구이지 뒤집힌 부호를 되돌리는 도구가 아니다.
  ⚠ 실제로 롱온리 F2/F3 는 **부호가 반대** 였다(PIT t 0.60 vs 1.21). 롱숏으로 바꾸면
    패자 다리가 들어오므로 부호가 논문 쪽으로 돌아설 수 있다 — 그것이 이 등록의 도박이다.
    안 돌아서면 «이 유니버스에서 FIP 은 부호부터 성립하지 않는다» 로 닫는다.
- 회전율을 반드시 싣는다. 6개월 보유 + 월말 리밸이면 겹치는 포트폴리오라 구조적으로
  저회전이어야 한다 — 아니면 구현이 틀렸다. 비용 5·10·20bp 편도를 전부 싣는다.
- 숏 다리의 차입 비용은 이 랩에 없다. **없는 것을 있는 척하지 않는다** — 결과에
  «차입비용 0 가정» 을 명시하고, 그것이 대형주라 작을 것이라는 변명은 적지 않는다.

## 하지 않을 것

- 분위 수를 바꾸지 않는다. 5분위는 논문의 선택이다. 3·10 분위를 돌려 좋은 것을 고르면
  그것이 최적화다(x-fip 이 N 스윕 10/20/30 에서 최고를 골라 부풀림 0.27 을 안았다).
- 보유기간을 바꾸지 않는다. 6개월은 논문의 선택이다.
- 시총 하한을 따로 걸지 않는다. 2026-08-25 부터 20% 하한이 밑동 기본이라 자동 적용된다.
  FIPMCF 가 이미 «하한은 편향을 절반으로 줄이지만 PIT 답을 안 바꾼다» 를 실측했다.
- 롱온리 변형을 등록하지 않는다. 그것은 x-fip-cont/disc 가 이미 쟀고 둘 다 죽었다.
  다시 등록하면 같은 것을 두 번 세는 것이고, 가족 수만 늘려 임계를 올린다.
- 표본 안 성적으로 배포 목록에 올리지 않는다.

## 가족 수와 임계

현재 랩 PIT 가족 111종. 이 등록으로 **115종**이 되고 다중검정 임계가 그만큼 올라간다.
넷을 다 세는 것이 맞다 — 거울과 비중립 대조는 «안 쓸 규칙» 이 아니라 판정에 필요한
측정이므로, 세지 않으면 그만큼 임계를 속이는 것이 된다.
