# 사전등록 — 프로그인더팬을 «보유기간» 축으로 · 2026-08-24, 돌리기 전에 확정

## 왜 다시 등록하나 — 그리고 무엇이 다른가

사용자 판단(2026-08-24) «프로그인더팬으로 알파 낼 수 있을 것 같다».

🚨 **원 규칙(x-fip)은 이미 재고 뺐다.** 2026-08-18 실측 —
    초과 CAGR +5.90%p · Δ샤프 +0.119 · t 1.49
    **시점정확(PIT) t 0.35 · PIT 초과 +1.12%p · 생존편향 5.71%p**
    N 스윕 부풀림 0.27(10/20/30 의 t 가 1.14/1.22/1.49 였고 최고를 골랐다)
    짝 규칙 x-cntd 는 **PIT 초과가 −0.08%p 로 음수**였다.
  즉 초과수익 5.90%p 중 5.71%p 가 생존편향이었다. **그 규칙을 되살리지 않는다.**

**이 등록이 재는 것은 다르다.** Da·Gurun·Warachka(2014)의 주장은 둘이다.
  ⑴ 정보이산성(ID)이 낮은 종목이 더 오른다        ← x-fip 이 잰 것. **기각됐다.**
  ⑵ ID 가 낮은 종목은 모멘텀이 **더 늦게 반전한다** ← 아무도 안 잰 것. **이것을 잰다.**
⑴은 «무엇을 살지» 이고 ⑵는 «얼마나 오래 들지» 다. 랩은 보유기간을 규칙마다 고정해
왔으므로(월말 리밸 = 1개월) ⑵는 구조적으로 잴 수가 없었다.

## 정보이산성(ID) 정의 — 여기서 못박는다

원 함수는 x-fip 을 지우면서 소스에서 함께 사라졌다. 논문 정의를 그대로 다시 적는다.

    형성창 = [i−251, i−21] (12-1 모멘텀과 같은 창)
    PRET   = 그 창의 누적수익
    %pos   = 그 창에서 일간수익 > 0 인 날의 비율
    %neg   = 그 창에서 일간수익 < 0 인 날의 비율
    ID     = sign(PRET) × (%neg − %pos)

ID 가 **낮을수록** 정보가 잘게 나뉘어 온 것이다(논문의 «연속적 정보»).
⚠ 유효일이 창의 60% 미만이면 None. 랩의 다른 창 함수와 같은 규약이다.

## 규칙 — 셋을 **쌍으로** 등록한다

공통: 매 월말, 12-1 모멘텀 상위 30을 먼저 고른다(= 이미 있는 x-mom12 와 같은 선택).
그 30 안에서만 ID 로 가르고, **보유기간만** 달리한다. 동일가중.

**F1 기준선 — 모멘텀 상위 30 · 1개월 보유**
  월말마다 다시 뽑는다. 랩의 x-mom12(상위 10)와 크기만 다르고 구조는 같다.
  ⚠ 이것이 없으면 아래 둘의 «오래 들어서 좋아졌나» 를 말할 수 없다.

**F2 연속정보 · 6개월 보유** — 상위 30 중 **ID 하위 절반**(연속적)을 6개월 보유.
**F3 이산정보 · 6개월 보유** — 상위 30 중 **ID 상위 절반**(이산적)을 6개월 보유.

🚨 **F3 이 이 등록의 핵심이다.** 논문이 맞다면 F2 > F3 여야 한다. 둘이 비슷하면 ID 는
  지속성을 재는 것이 아니고, 그때는 «F2 가 기준선보다 낫다» 는 결과가 나와도 그것은
  ID 가 아니라 **보유기간을 늘린 효과**다. 거울 없이 F2 만 등록하면 그 둘을 못 가른다.

## 미리 적어 두는 실패 조건

- **PIT 로 재서 t 가 1 미만이면 그것으로 끝이다.** 원 규칙이 PIT t 0.35 로 죽었고,
  이 등록은 같은 자료·같은 유니버스를 쓴다. 소급 수치가 좋아도 PIT 이 답이다.
- F2 와 F3 의 차이가 Δ샤프 0.1 미만이면 ID 는 지속성을 못 가른 것이다 — 그렇게 적는다.
- F2 가 F1 보다 나은데 F3 도 F1 보다 나으면, 그것은 ID 가 아니라 «6개월 보유» 가 한 일이다.
- 보유기간을 6개월 하나만 돌린다. 3·6·12를 돌려 좋은 것을 고르면 그것이 최적화다
  (원 규칙이 N 스윕에서 정확히 그 문제로 부풀림 0.27 을 안고 있었다).
- 회전율을 반드시 싣는다. 6개월 보유는 구조적으로 저회전이어야 한다 — 아니면 구현이 틀렸다.

## 판정

표본 안 성적으로 배포 목록에 올리지 않는다. 이 등록이 묻는 것은 «ID 가 지속성을
가르는가» 라는 **구조 질문**이고, 규칙 하나의 성적이 아니다.
