# 사전등록 — 거장 순매집을 펀드에 얹을 수 있나 (GURUACC) · 2026-09-20

풀카드: 없음 (선별기 `build/fund_fit.py` 8위 · 펀드 상관 −0.01 로 **열 중 가장 독립적**)
규칙: `x-guruacc-q` · `x-guruacc-mix10`

## 0. 무엇을 묻고, 무엇을 못 묻나

랩에 이미 `x-guruacc`(월말 리밸런스)가 게시돼 있다. **그것을 다시 판정하는 것이 아니다.**
이 등록이 묻는 것은 하나다 —

> **«우량성장 30 위에 이 축을 얹을 수 있나?»**

그래서 원 규칙을 그대로 쓰지 않고 **펀드에 맞춰 바꾼 판**을 만든다. 바꾸는 것은 둘:

| | 원 규칙 `x-guruacc` | 이 등록 `x-guruacc-q` |
|---|---|---|
| 리밸런스 | 월말 | **분기 1회**(자료가 생기는 달의 말) |
| 판정 잣대 | S&P 500 PR | **S&P 500 TR**(펀드의 확정 잣대 B) |

**왜 분기로 바꾸나** — 원 규칙의 회전이 **연 4.18회**다. 펀드는 분기 리밸이고
매월 리밸의 비용이 이미 측정돼 있다(**연 −0.97%p**). 13F 자체가 분기 자료이므로
월말마다 다시 고르는 것은 **같은 정보를 세 번 읽는 것**이다.
⚠ 그래서 성적이 원 규칙과 다르게 나올 것이고, **그것을 «개선»으로 읽지 않는다.**
다른 규칙이다.

## 1. 🚨 이 자료의 가장 큰 결함을 먼저 적는다 — 매니저 생존편향

오늘 세어 보고 알았다(`build/fix_guru_count.py`):

| | |
|---|---|
| 패널의 매니저 | 분기마다 **22~27명**(2013-06 22 → 2020-12 이후 27) |
| **2026-06-30 까지 제출을 계속하는 매니저** | **27명 전원** |
| 중간에 사라진 매니저 | **0명** |

**명단을 오늘 기준으로 골랐다.** 망했거나 접었거나 13F 제출을 멈춘 운용사는
애초에 패널에 없다. `guru_history.json` 의 `limits` 여섯 줄 어디에도 이 항목이 없다.

그리고 **나중에 추가된 매니저의 과거가 소급으로 다 들어 있다** — 히말라야(리루) 27분기 ·
아크(우드) 39분기 · 아팔루사(테퍼) 42분기 · 엘리엇 26분기 · 퍼싱스퀘어 **1분기**.
2015년에는 그들을 «거장» 명단에 넣지 않았을 수도 있는데, 지금 패널은 넣고 있다.

> **이것이 이 등록의 핵심 위험이고, 실패 조건 F8 로 정면에서 잰다.**

## 2. 규칙 — 계산 전에 못박는다

### 2-1. 유니버스
그 달 **실제 S&P 500 편입명단**(`data/index_history.json`). 소급 패널을 쓰지 않는다.

### 2-2. 점수
각 분기 `q` 에 대해, 매니저 전원의 **합산 보유금액** `V(t,q)` 를 종목별로 모은다.

> **점수 = V(t,q) / V(t,q−1) − 1** (직전 분기 대비 증가율)

🚨 **`V(t,q−1) = 0`(신규 진입)은 후보에서 뺀다.** 분모가 0이면 증가율이 정의되지 않는다.
«무한대» 를 큰 값으로 바꿔 넣으면 그 순간 규칙이 **«신규 진입 종목 사기»** 가 되고,
그것은 다른 규칙이다. 원 규칙의 문장도 «금액 변화율» 이다.
⚠ **빠진 신규 진입이 몇 건인지는 결과문서에 반드시 싣는다** — 안 재고 버리는 것과
재고 버리는 것은 다르다.

### 2-3. 시점
- **자료 가용**: 분기말 **+45일**(13F 마감). 그 뒤 **첫 월말**에 형성한다.
  → 3월말 분기는 5월말, 6월말 분기는 8월말, 9월말 분기는 11월말, 12월말 분기는 2월말.
- **보유**: 다음 형성월까지 **3개월**. 분기 중 표류는 그대로 둔다.
- **진입**: 형성월 종가로 비중을 잡고 **그 다음 달부터** 수익을 센다
  (SWING1020 에서 하루 선행 누설을 만든 자리다).

⚠ **펀드와 형성월이 어긋난다**(펀드 3·6·9·12 / 이쪽 2·5·8·11).
**맞추지 않는다** — 맞추려면 자료를 최대 3개월 묵혀야 하고, 그러면 신호가 아니라
지연을 재게 된다. 실제 운용에서 두 슬리브가 다른 달에 리밸런스하는 것은 정상이다.

### 2-4. 바스켓
**상위 10종 · 동일가중**(원 규칙과 같은 크기).

### 2-5. 비용·잣대
왕복 **25bp**(펀드와 같은 값). 잣대 **B = 바스켓 TR − S&P 500 TR**.

### 2-6. 혼합판 `x-guruacc-mix10`
**펀드 90% + 이 축 10%.** 비중은 **종목 수준에서 합친다**.

**왜 10%인가** — VALSLEEVE 는 다섯 축을 묶은 것이라 20%였다. 이것은 **단일 축**이고
단독 t 가 1.6 이다. 한 축에 20%를 주는 것은 그 축의 증거에 비해 크다.
**결과를 보고 배합을 바꾸지 않는다**(다른 배합은 참고표로만 싣는다).

## 3. 결과문서에 반드시 실을 것

1. 분기별 후보 수 · **신규 진입으로 빠진 건수**
2. 펀드와의 종목 겹침(비중·종목 수)
3. 단독/혼합 성적 — 초과·TE·t·IR·승률·회전·MDD (비용 전후)
4. **F8 매니저 생존편향 검정**(§4) 결과
5. 섹터 쏠림 · 축별 기여가 아니라 **매니저별 기여**(누가 이 성적을 만들었나)
6. 앞/뒤 절반 · 국면(변동성 3분위)
7. 셔플 200회

## 4. 기각 조건

| | 조건 |
|---|---|
| **F1** | 단독 초과(비용 후) **≤ 0** |
| **F2** | 혼합판 **IR 개선 < 0.05** |
| **F3** | 펀드 위 증분 알파 **t < 2** |
| **F4** | 셔플 200회 **백분위 < 95** |
| **F5** | 후보 30종 미만인 형성 분기 **> 10%** |
| **F6** | 펀드와 겹침 **비중 50% 초과** |
| **F7** | 표본 **뒤 절반에서 증분 부호 반전** |
| **F8** | 🚨 **매니저 생존편향** — **2013-06 에 이미 패널에 있던 매니저만**으로 다시 재어 단독 초과가 **전체 판의 절반 미만**으로 줄면 기각 |

**F8 을 푸는 법** — 2013-06 명단(22명)으로 패널을 고정하고 같은 규칙을 다시 돌린다.
그 22명도 «오늘 살아 있는 사람» 이라 편향이 완전히 빠지지는 않는다.
**그러나 «나중에 추가된 5명의 소급 기여»는 이것으로 걷힌다.** 완전한 교정이 아니라
**방향과 크기의 하한**이고, 결과문서에 그렇게 적는다.

## 5. 예측 — 계산 전에 적는다

| | 예측 | 왜 |
|---|---|---|
| **P1** | 분기판 단독 초과가 원 규칙의 PIT **+5.39%p 보다 작을 것** | 월말→분기로 늦추면 정보가 묵는다 |
| **P2** | 펀드와 겹침 비중 **10% 미만** | 선별기에서 상관이 −0.01 이었다 |
| **P3** | 증분 알파 t 가 **2를 못 넘을 것** | 선별기 t 1.52 에서 분기화·비용을 빼면 더 내려간다 |
| **P4** | **F8 에서 초과가 줄되 절반 밑으로는 안 갈 것** | 추가된 5명 중 넷이 최근 분기 비중이 작다 |
| **P5** | 매니저별 기여가 **한두 명에 몰릴 것** | 금액 합산이라 버크셔·AQR 같은 큰 곳이 점수를 지배한다 |
| **P6** | 신규 진입으로 빠지는 후보가 **분기당 20건 이상** | 거장들은 매 분기 새 종목을 산다 |

⚠ **P3 이 맞으면 F3 에 걸려 기각이다. 그것이 내가 보는 그림이고, 미리 적는다.**

## 6. 안 할 것

1. **결과를 보고 배합(10%)·크기(10종)·분기 정렬을 바꾸지 않는다.**
2. **신규 진입을 포함하는 변형을 만들어 좋은 쪽을 고르지 않는다**(§2-2).
   빠진 건수만 세어 싣는다.
3. **매니저를 골라내지 않는다.** «버크셔만» 이나 «퀀트 제외» 같은 판은 만들지 않는다 —
   그것은 이 표본에서 고르는 것이다. F8 의 22명 고정은 **날짜로 정한 것**이지
   성적으로 고른 것이 아니다.
4. **월말판(원 규칙)과 나란히 놓고 나은 쪽을 취하지 않는다.** 판정은 분기판으로만 한다.
