### 1.1 T01 — MTP 속도 오버레이 (GHM MED · 규모 ½) · 오버레이 · 가격 상태 · 전환점

### 1.3 T03 — 저베타 소매 + 베타 채움 (VW) · 상시 + 선물 채움 · 저위험 이상현상

- **근본 이유**: 레버리지를 못 쓰는 투자자가 고베타를 비싸게 사서 증권시장선이 평평해진다(Black 1972 · Frazzini–Pedersen 2014). 벤치마크 운용역도 같은 방향으로 끌린다(Baker–Bradley–Wurgler 2011).
  저베타를 사고 모자란 베타를 지수 선물로 채우면 제약 없는 쪽이 알파를 가져가고, 랩의 반복 실패(방어주를 들고 시장 프리미엄을 잃음)를 피한다. **«꾸준함 카드»** — 급락 방어를 약속하지 않는다(FP 예측 3: 자금 경색기에 약함).

- **단계** T03-S1: GHM Rebound 상태면 S = B(약세장 뒤 반등은 고베타 · 부실주가 이끈다 — DM) — 측정만.
- **대조**: 채움 없는 Lo 20(구 T10) · Lo 20 EW + 채움 · VAR Lo 20 + 채움 · AQR BAB 오버레이(롱숏 · 측정만 · 라이선스 제한 — 결과 비공개).
- **G4(필수)**: 채움 판 X > 채움 없는 판 X(겹친 달).
- **창**: L-R 1968-07~2026-07(58.1년) · 문헌 1968-07~2012-03 · **L-C 2012-04~2026-07(14.3년)** · 랩 밖 1968-07~2008-12.
- **S 층**: 랩 PIT S&P 500 에서 60개월 베타 하위 20% VW(6월 재구성) + (1 − β̂)(SPY − BIL) · β̂ 는 보유 기준 60개월(§8) · 쌍둥이 SPLV + 채움 · 충실도 ρ(S_PIT − SPY, S_French − Mkt) ≥ 0.6.
- **결함**: 자금 경색기 부진 · 금리 급등기 방어 업종의 금리 민감도 · β̂ 추정 오차 · 6월 연 1회 재구성이라 베타가 낡는다.

### 1.8 T13 — CAPE 가치 + 모멘텀 틸트 50~150% (CAPE 재계산) · 오버레이 · 밸류에이션 타이밍
- **위임(D2)**: S&P 선물 ±5%(허용 · 슬리브 50~150% = 펀드 주식 노출 95~105%).
- **근본 이유**: 밸류에이션이 높으면 장기 기대수익이 낮다. 가치 단독 타이밍은 모멘텀과 싸워(능동수익의 모멘텀 노출 −0.2~−0.3) 매수보유를 못 이긴다. 12개월 모멘텀을 촉매로 더하면 가치 함정이 준다(AQR «Sin a Little» 2017).
- **규칙**: CAPE 를 다시 계산한다 — P = Shiller 월평균 가격(월말 가격이 아님) · 실질화 CPI 1개월 늦춤 · E 6개월 늦춤 · 10년 평균 실질 E · EP = 1/CAPE.
  tilt_V = (trim(EP_t) − med(EP))/(P95 − P5) · tilt_M 은 같은 식을 12개월 시장 초과수익에 · 분위 창은 1881 부터 확장 · 1941 이후 60년 이동. w_t = clip(1 + ½(tilt_V + tilt_M), 0.5, 1.5) · S = B + (w − 1)(Mkt − RF).
  Shiller 파일의 CAPE 열은 읽지 않는다.
- **단계** T13-VM: 모멘텀 절반 자체가 가치 타이밍의 약점(모멘텀과 싸움)을 고치는 단계(G4 로 잰다).
- **대조**: 모멘텀만(같은 척도 함수 · tilt_M 만 — 주 대조 · w_M = clip(1 + tilt_M, 0.5, 1.5) · 원문 단일 신호 척도 50~150%) · 상수 노출 쌍둥이(창 실현 평균 w) ·
  가치만(C0 · w_V = clip(1 + tilt_V, 0.5, 1.5)).
- **G4(필수)**: VM X > 모멘텀만 X ∧ VM X > 상수 노출 X(원문 표 5 에서 모멘텀만이 VM 보다 SR 이 높았다). VM 은 두 단일 신호 포지션의 평균이라
  (절단이 안 걸리면 X_VM = ½(X_V + X_M)) «VM X > 모멘텀만 X» 는 «가치 타이밍 X > 모멘텀 타이밍 X» 와 같다 — 원문 표 5 의 비교다.
  구현 초안의 반 척도 대조(1 + ½tilt)는 이 조건을 «반 척도 가치 X > 0» 으로 무너뜨려 등록 전에 고쳤다(적대 검토 · §8.3).
- **창**: L-R 1928-01~2026-07(98.6년) · 문헌 1928-01~2015-12 · **L-C 2016-01~2026-07(10.6년)** · 랩 밖 = 전 창.
- **S 층**: S = SPY + (w − 1)(SPY − BIL) · 같은 재계산 CAPE(모멘텀은 2007-06 부터 SPY − BIL) · ETF 쌍둥이 없음 · 충실도 = w 상관(SPY 판 대 French 판 · 2016-09~2026-07) ≥ 0.9(수익 아님).
- **결함**: 밸류 수준의 구조적 이동 · 평균 포지션 102%(1900–2015) · 93%(1958–2015) → 노출 차가 X 에 섞임(상수 노출 쌍둥이로 가른다) · E 보간(6개월 늦춤으로 막는다).
- **D5 공지**: Shiller 파일 CAPE 열 2026-08 = 41.12(2000-01 43.77 근처) — 재계산 값은 계산하지 않았다. 가치 절반이 하한 쪽으로 기울 것을 공지만 하고, 전방 원장에 들어가면 «현재 w» 를 첫 결정으로 남긴다.

### 2.3 H_T0 (배치 가설 · 유일한 확인 검정)
- **H0**: 청정 창 X 평균의 카드 합이 0 이하 — «문헌 · 랩 표본 밖에서 이 기전들은 펀드틀 초과를 내지 못한다».

  T02 를 H_T0 에서도 뺄지는 사용자 확인 대기 — §8.4).
- **통계**: Z = Σ_i t_i / √(Σ_i Σ_j ρ_ij) · t_i = 카드 i 청정 창 X 의 NW(6) t · ρ_ij = 두 카드 청정 창 월 X 의 겹친 달 상관(겹침 ≥ 36개월 · 아니면 0) · ρ_ii = 1.
  t 가 서지 않은 구성원(F0 미달 · 청정 창 자료 없음)은 분자에 0 · 분모에 남긴다(보수).
- **α**: 한쪽 0.025 · 기각 ⇔ Z ≥ 1.959964. **배치 FWER 전부를 이 하나에 쓴다(D4).**
- **크기(합성 · 등록 전 · 적대 검토)**: 등록한 청정 창 10개 · NW(6) t 로 귀무 3,000회 — 상관 0 에서 기각률 0.030(z 표준편차 1.06 · 91개월 창에서 NW 가 과분산) ·
  공통 상관 0.3 에서 0.023 · 부호 섞임 0.023. ρ_ij 는 설계 식 그대로 겹친 달 상관이다 — 부분 겹침을 n_ij/√(n_i n_j) 로 줄이지 않으면 ρ > 0 에서 분모가 커져 보수 쪽이고,
  줄이면 공통 상관이 있을 때도 상관 0 의 크기(0.030) 쪽으로 갈 것이다(줄인 식은 시뮬레이션하지 않았다 — 추론). 설계 식을 그대로 두고 이 크기를 공개한다
  (적대 검토가 낸 두 길 가운데 «공개» · §8.3).
- **D2 민감도(α 없음 · 보고만)**: T02 를 뺀 같은 식을 저장소 밖 산출에만 남긴다(`H_T0_sens_exT02` — T02 가 AQR 파생이라 게시하지 않는다 · D3). 확인 검정은 H_T0 하나다.

## 3. 자료 · 판 · 해시 · 라이선스 (D3 · B0)

### 3.1 보관 규칙
- 원자료는 **저장소 밖 캐시**(`$TBATCH_CACHE` 또는 `%TEMP%/tbatch_cache` — `t_data._cache_guard` 가 저장소 안 경로를 거부한다)의 `raw/` 에만 있다. 저장소에는 연방 통계(FRED · ALFRED)만 `data/_tb_fred/` 에 고정한다.
- **캐시 표지**: 캐시 뿌리마다 무작위 표지(`meta/cache_id.txt`)를 두고 그 SHA-256 을 명세 `cache_identity` 에 적었다. 러너는 명세와 같은 표지를 가진 캐시에서만 굽는다 —
  `TBATCH_CACHE` 를 새 폴더로 돌려(시작 표식 · 산출이 없는 캐시) 다시 굽는 길을 막는다(적대 검토).
- **백업**: 고정본은 다시 받아도 같은 SHA 가 나오지 않는다(Cboe 는 이미 이틀 붙었고 AQR 는 갱신마다 전체 이력을 다시 짓는다). %TEMP% 정리에 대비해 SHA 를 대조하며
  저장소 밖 · %TEMP% 밖 사적 폴더(`%LOCALAPPDATA%/yeodoo_private/tbatch_cache_backup` — 고정본 63 · 표지 · xlrd 10 = 74개 · 21MB)에 복사했다(`t_data.py --backup` · 복원 `--restore` ·
  임시 캐시로 복원 → `--check` 통과를 확인). 백업도 커밋 · 게시하지 않는다(D3).
