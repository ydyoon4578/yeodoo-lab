# 사전등록 — 종목 RRG 판: 주간 4분면이 다음 주를 가르나 · 2026-09-23

사용자 지시 2026-09-23: 「explorer.html 종목으로 rrg 로테이션 판 만들어보자」.

🚨 **이 문서는 계산 전에 커밋한다.** 아래 실패 조건·예상은 결과를 보기 전에 못박은 것이고,
  돌린 뒤에 고치지 않는다. 고쳐야 할 일이 생기면 그 사실을 결과 문서에 적는다.

## 0. 무엇을 묻나 — 그리고 무엇은 이미 답이 나왔나

어제(PREREG-2026-09-22-RRG) **팩터 110종 · 월간** RRG 를 쟀고 **기각(F3)** 이었다 —
시계 방향 회전 67.4% 가 셔플 귀무 중앙 67.0% 와 같았다. 회전은 산식이 만든 것이었다.

오늘 그리는 것은 **다른 모집단 · 다른 주기**다: **종목 518종 · 주간**. 어제의 판정을
그대로 옮겨 붙이면 재지 않은 것을 잰 것처럼 쓰는 셈이라, 같은 검정을 이 판에 다시 건다.

🚨 **판은 결과와 무관하게 만든다**(사용자 지시). 이 등록이 정하는 것은 판을 만들지 말지가
  아니라 **판에 무슨 딱지를 붙이고 무슨 말을 적는가**다. 기각이면 «기각» 딱지와 그 이유를
  판 머리에 싣는다. 통과해도 «사라» 는 적지 않는다(§4).

## 1. 설계 — 계산 전에 고정

| 항목 | 값 | 왜 이 값인가 |
|---|---|---|
| 모집단 | **518종** — `data/stocks.json` 의 `stocks[]` 전부 | explorer 202개 전략의 `holdings.tickers` 합집합을 실측했더니 **정확히 이 518종**이다(유니버스 전체를 쥔 전략이 있다). 더하거나 빼지 않는다 |
| 가격 | `data/sd/<t>.json` 의 `pxd`(yfinance 배당조정 종가) · 날짜는 `stocks.json` 의 `pxd_dates` | 랩 일간 격자 그대로. 새로 받지 않는다 |
| **벤치** | **S&P 500(PR)** — `data/bench_px.json` 의 `spx` 하나 | 어제 등록과 같다 |
| 주기 | **주간** — 주(월~금)의 마지막 거래일 종가 | 종목 RRG 의 표준 눈금. 일간·월간을 시도하지 않는다 |
| 되돌아보기 | **n = 12주** | 어제와 같은 **수**(12)를 주 단위로 쓴다. 다른 값을 시도하지 않는다 |
| **산식** | `build/rrg.py` 의 `rrg_axes()` **그대로** — RS-Ratio = 100 + (RS − SMA₁₂)/SD₁₂, RS-Mom = 같은 정규화를 RS-Ratio 1주 차분에 | 🚨 산식 판을 바꾸지 않는다. 빠른 계산을 위해 numpy 로 다시 쓰면 **몇 종목에서 `rrg_axes()` 와 소수 6자리까지 같은지 먼저 대조**하고, 다르면 멈춘다 |
| 사분면 | 주도(≥100,≥100) · 약화(≥100,<100) · 부진(<100,<100) · 회복(<100,≥100) | 어제와 같다 |
| 검정 창 | 형성 주 **2016-09-02 ~ 2026-09-11** (다음 주 = 2026-09-18 까지) | 어제와 같은 10년. 축은 2009 부터 계산해 앞머리를 데운다 |
| 다음 주 초과 | 종목 주간 수익 − S&P 500 주간 수익 (%p, 단순차) | |
| 현재 위치 | **2026-09-18** 로 끝나는 주 | 이번 주(09-21·22)는 부분 주라 **뺀다** — Mom 축이 1주 차분이라 이틀짜리 주는 다른 잣대가 된다(어제 §6 과 같은 이유) |

⚠ **알고 있는 편향 둘** — 계산 전에 적는다.
- 종목 가격은 **배당조정**, 벤치는 **가격지수**다. RS 에 연 약 2%p(주 0.04%p) 의 상향
  기울기가 섞인다. 12주 z 점수가 수준을 대부분 지우므로 작다고 보지만 0 은 아니다.
- 518종은 **오늘의 편입 종목**이다(생존편향). 그래서 F6 을 둔다.

## 2. 미리 적어 두는 실패 조건

하나라도 걸리면 그 항목은 **기각**이고 되돌리지 않는다.

- **F1** 주도 사분면의 **다음 주 초과** 평균이 부진 사분면보다 **크지 않으면** 기각.
- **F2** 그 차이의 t(묶지 않음, Welch) 가 **1.5 미만**이면 「구별 불가」.
  ⚠ 1.5 는 어제 등록과 같은 값이다.
- **F3** 🚨 **시계 방향 회전 비율이 셔플 귀무의 95 백분위를 못 넘으면** 기각.
  각 종목의 주간 수익을 **그 종목의 유효 구간 안에서** 뒤섞고(벤치는 그대로) 같은 산식으로
  다시 만든다. 셔플 **200회**, 시드 20260923 으로 고정. 전이는 검정 창 안의 것만 센다.
- **F4** 사분면당 관측(종목·주 쌍)이 **500 미만**인 칸이 하나라도 있으면 **측정 불가**.
- **F5** 🚨 같은 주의 518종은 같은 시장을 탄다. **주 단위로 묶어**(각 주의 「주도 평균 −
  부진 평균」 하나를 관측으로) t 를 다시 낸다. 묶지 않은 판정과 **갈리면 「보류」**.
- **F6** 🚨 **생존편향.** 관측을 **그 시점에 실제로 S&P 500 ∪ NASDAQ 100 에 들어 있던
  종목·주**로만 줄여(`data/index_history.json` · 그 주가 속한 달의 **전월말** 명단 —
  그때 알 수 있던 것) F5 의 묶은 차이를 다시 잰다. 부호가 전체와 **다르면 「보류」**.
  ⚠ 편출·상장폐지 종목은 518종에 없으므로 이것으로도 생존편향이 다 지워지지 않는다 —
    편입 **전** 구간(오른 뒤에 들어온 종목의 과거)만 걷어 낸다. 결과 문서에 그 한계를 적는다.

## 3. 미리 적어 두는 예상 (맞았는지 채점한다)

1. 🚨 **F1 은 걸릴 것이다(기각).** 주간 종목 수익에는 **단기 반전**이 있다 — 지난주 오른
   종목이 다음 주 진다. 주도는 «RS 가 평균 위이고 오르는 중» 이라 반전을 가장 크게 맞고,
   부진은 그 거울이라 반등을 받는다. 그래서 **주도 < 부진** 으로 본다.
2. **F3 도 걸릴 것이다.** 어제처럼 실제 시계 비율이 셔플 귀무 안에 들 것이다.
3. **F5 로 묶으면 |t| 가 크게 준다** — 관측이 약 27만 개에서 약 520주로 준다.
4. **지금(2026-09-18) 가장 많은 종목이 「부진」 에 있을 것이다.** 시장 폭이 무너진 국면이고,
   이번엔 되돌아보기가 12주라 어제(12개월)와 달리 최근 붕괴를 담는다.

## 4. 무엇을 하지 않나

- 🚨 **이 4분면으로 전략을 만들지 않는다.** 「주도 종목을 사라」·「부진을 피하라」·
  「회복을 사라」 어느 것도 이 등록의 산출물이 아니다. 그것은 **별도 등록**이 필요하다.
  (§3-1 이 맞아 «부진이 낫다» 가 나와도, 그것을 반전 전략으로 옮기는 일은 여기서 안 한다 —
  주간 반전은 이 랩이 이미 «주간 반전» 규칙으로 쟀고 PIT 에서 t 가 4.00 → 1.02 로 무너졌다.)
- 되돌아보기(12주)·컷(100)·산식 판·주기를 움직여 더 나은 그림을 찾는 일.
- 모집단을 「잘 도는 종목」·섹터로 다시 잘라 검정하는 일. 판 위의 섹터·전략 필터는
  **보기용**이고 검정에 들어가지 않는다.
- 부분 주(2026-09-21~)를 검정이나 현재 위치에 넣는 일.
