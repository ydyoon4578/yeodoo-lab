# 사전등록 — 조용함의 횡단면 보상이 2021 에 꺼졌는가 (QUIETIC) · 2026-08-13

**이 문서는 돌리기 전에 커밋한다.** 결과는 `-RESULT.md` 로 따로 낸다.

---

## 0. 먼저 — 이 조사의 출발 전제가 틀렸었다

사용자에게 "통계 계열 11종이 시점정확(PIT)에서 통째로 죽는다"고 보고했다. **그 진단이
틀렸다.** 실측으로 셋이 뒤집혔다(전부 `data/tech_strategies.json` 재계산):

| 층 | 통계 11종 중앙 | 나머지 중앙 |
|---|---|---|
| 랩 t (S&P 500 PR 잣대) | 1.05 | 1.58 |
| 랩 t (동일가중 `vs_traded`) | **−0.42** | 0.36 |
| 같은 창 소급 t | **−0.49** | 0.94 |
| PIT t | −0.47 | 0.52 |

- **PIT 이 죽인 게 아니다.** 창·N 을 고정하고 유니버스만 바꾼 낙차는 계열 0.317 ·
  나머지 0.502 로, 이 계열이 오히려 **덜** 깎인다. 같은 창 소급에서 이미 죽어 있다.
- **"PIT t 가 1 을 못 넘는다"는 랩의 기본값이다.** 79종 중 68.4% 가 t ≤ 0.67,
  중앙 0.40. 계열의 병이 아니다.
- 내가 인용한 편향 컬럼(`bias_cagr` 중앙 5.06)은 그중 5.52%p 가 **벤치마크 자신의
  편향**이라 전 규칙 공통이고 아무 정보가 없다. `bias_excess` 로 보면 중앙 −0.46 이다.

이 문서는 그 정정 위에서 다시 세운 것이다. **틀린 전제로 시작했다는 사실을 지우지 않는다.**

## 1. 그래서 특별한 것은 무엇인가 — 2021 이후 구간

주간 초과수익 기준, 분할점은 PIT 창 시작일(2021-07-30):

| | 2016-09 ~ 2021-07 (246주) | 2021-07 ~ 2026-08 (254주) |
|---|---|---|
| 계열 11종 IR 평균 | **0.63** | **0.22** |
| 나머지 68종 IR 평균 | 0.67 | 0.61 |
| 계열 초과CAGR 평균 | 7.51%p (순열 p=0.14) | 2.24%p (순열 p=**0.005**) |

**계열 10/11 이 후반에 악화**(중앙 ΔIR −0.56), 나머지는 68종 중 38종 · 중앙 −0.06.
랩은 안 꺼졌고 계열만 꺼졌다.

⚠ 손쉬운 설명 하나는 **이미 실패했다.** 계열 공통성분 로딩과 ΔIR 의 상관은 79종에서
**−0.094**(터셜별 −0.150/−0.133/−0.102 로 평평)이고, 로딩이 높은 비계열 규칙 둘은
오히려 좋아졌다(`x-epsacc` +0.27 · `x-ltrev` +0.77). **수익률 공간에는 답이 없다.**

## 2. 가설

11종은 좌표계만 다를 뿐 하나를 산다 — 최근 252일이 **조용한** 종목.

> **H1. 조용함의 횡단면 보상(rank IC)이 2021 에 꺼졌다.**
> 롱온리·동일가중 바스켓 수익률은 공통 롱온리 성분에 지배돼(비계열 규칙조차 로딩 0.67)
> 그 뒤집힘을 보여주지 못한다. 그래서 로딩이 낙차를 못 정렬했고(−0.094), 그래서
> `incr5` 이웃 지목도 잡음이었다.

⚠ 이것은 `STAT2 §4`(경로·분포 통계가 서로를 이웃으로 안 지목한다, 네 번 반복)의
**설명이지 재발견이 아니다.** 증분 알파는 수익률 공간에서 이웃을 찾는데, 이 계열의
공통 인자가 신호 공간에 있다면 그 검정은 애초에 볼 수단이 없다.

## 3. 무엇을 재나 — 새 규칙 없음, 새 채점기 없음

측정 대상은 기존 11 규칙의 **점수**다. `build/tech_backtest.py` 의 `xsec_score_at()` 을
그대로 부른다(랩 레그·PIT 레그가 이미 같이 부른다). 플래그 `--ic` 하나를 얹어 월별 IC 를
`data/_ic_diag.json` 에 쓴다.

🚨 **`tech_strategies.json`·`pit_strategies.json` 은 한 바이트도 안 건드린다.**
실행 전후 해시를 결과 문서에 싣는다.

1. 랩 월말 120개 × 11종: 그달 점수와 **다음 달 수익**의 스피어만 rank IC.
   매수 방향으로 부호 정렬 → 양수 = 신호가 듣는다. 결측은 0 으로 안 채운다.
2. 대조군: PIT 이 돌아간 나머지 68종 전부 같은 방식.
3. 분할: PRE 2016-09~2021-07(59 월말) / POST 2021-07-30~2026-08(61 월말).
   **분할점은 PIT 시작일이고 결과를 보고 옮기지 않는다.**
4. 다리 분해: 매달 (상위 N − 풀 평균) 과 (풀 평균 − 하위 N) 을 따로 낸다.
5. 유니버스 불변성: POST 의 IC 를 소급 풀과 PIT 멤버 풀 양쪽에서 각각.

N 은 `nsel.n` 고정, 창 252일 고정.

## 4. 귀무가설

> 조용함의 횡단면 보상은 **애초에 없었다.** 계열의 랩 성적은 동일가중 유니버스
> 프리미엄(연 5.08%p)과 종목선택 없는 잡음이다. → PRE IC ≈ 0, ΔIC ≈ 0.

## 5. 사망 조건 — 하나라도 걸리면 기각

🚨 **t 문턱을 쓰지 않는다**(2026-08-13 에 랩 전체에서 없앴다). 효과 크기로 적는다.

| | 조건 | 뜻 |
|---|---|---|
| **K1** | 계열 PRE 평균 rank IC < **+0.010** | 보상이 애초에 없었다 → 답은 '잣대'로 확정. **기전 사망** |
| **K2** | ΔIC(POST−PRE) 계열 중앙 > **−0.015** | 뒤집힘이 없다. 사망 |
| **K3** | 대조 68종 중앙 ΔIC ≤ 계열 중앙 ΔIC | 랩 전체 현상. 사망 + §1 의 답이 '특별하지 않다'로 바뀐다 |
| **K4** | 계열 안 spearman(ΔIC, ΔIR) < **+0.30** | 신호공간이 수익공간 낙차를 설명 못함. 설명으로서 사망(사실은 남긴다) |
| **K5** | 경계 4종 추가 시 중앙 \|ΔIC\| 가 절반 미만으로 축소 | 경계가 결과를 만들었다. 사망 |
| **K6** | POST 를 반으로 갈라 ΔIC 가 한쪽에서만 음수 | '감쇠'가 아니라 **에피소드**로 적고 등급 없이 닫는다 |

K5 의 경계 4종: `x-rskew` · `x-coskew` · `x-volvol` · `x-earnvol`.

## 6. 미리 배제하는 변형 — 돌리기 전에 못박는다

- N 재최적화 금지 · 252일 창 변경 금지
- **`x-lbq`·`x-acorr` 제외 금지.** `x-lbq` 는 ΔIR +0.79 로 계열의 유일한 반례다 —
  빼면 그것이 p-해킹이다.
- 스피어만 고정(피어슨으로 안 바꾼다) · 분할점 이동 금지
- IC 요약은 평균과 중앙 **둘 다** 싣는다
- 선견(오라클) 레그 안 쓴다
- 실패해도 롱숏 버전으로 갈아타지 않는다

## 8. 실패해도 배우는 것
