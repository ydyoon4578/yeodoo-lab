## 1. ⒜ 가격 묶음 — **결합이 부분을 전부 넘었다. 그런데 무작위 가중도 넘었다**

Mom · negOsc · negResid · **후보 중앙 463종**(30종 미만인 달 0/148)

| | 월 롱숏 | t |
|---|---|---|
| 단일 Mom | +0.054% | 0.14 |
| 단일 negOsc | −0.147% | −0.55 |
| 단일 negResid | −0.091% | −0.24 |
| **결합(시총가중)** | **+0.252%** | **0.92** |
| 결합(동일가중) | +0.209% | 0.77 |
| 무작위 가중 200회 | −0.013% (sd 0.191) | **백분위 89.0** |

**결합이 세 부분을 전부 넘는다**(+0.252 > +0.054 > −0.091 > −0.147).
**이것이 오늘 나온 것 중 「섞는 것이 실제로 일했다」에 가장 가까운 수다.**

| | 조건 | |
|---|---|---|
| F1 | 롱숏 ≤ 0 | ✅ |
| **F2** | 묶음 안 최고 단일을 못 넘음 | **✅ 넘었다** |
| **F3** | 무작위 가중 상위 5% 밖 | **❌ 백분위 89.0** |
| F4 | 10bp 후 ≤ 0 | ✅ |
| F5 | 후보 30종 미만 | ✅ |

**F3 이 말하는 것** — 세 축을 **어떻게 섞어도** 비슷하게 나온다. 200번 중 22번이
동일가중보다 나았다. **즉 이득은 「가중치를 잘 골라서」가 아니라 「셋을 함께 써서」 온다.**
그건 좋은 소식인데, **동시에 이 등록이 잡으려던 것이 그것이다** —
가중치를 고른 값이 0 이면 결합 규칙으로 팔 것이 없다.

## 2. ⒝ 재무 묶음 — **측정 불가**

Cta · OL · TaxSurp · OCAT · negNOA · **후보 중앙 24종**(30종 미만인 달 **88/148**)

**다섯을 전부 가진 종목이 24종밖에 없다.** `Cta` 커버 20% 가 묶음 전체를 묶는다.
**등록서 §5 F5 대로 숫자를 내지 않는다.**

⚠ 예측 ③ 이 이것을 맞혔다 — *"⒝ 는 후보가 크게 줄어 F5 에 가까울 것"*.
**가까운 정도가 아니라 넘었다.**

## 3. 예측 판정 — 넷 중 둘

| | 예측 | 실측 | |
|---|---|---|---|
| P1 | ⒝ 재무가 ⒜ 가격보다 나을 것 | **⒝ 는 측정조차 못 했다** | **틀림** |
| P2 | ⒜ 는 F2 에서 걸릴 것 | **F2 를 통과했다**(결합 > 부분 전부) | **틀림** |
| P3 | ⒝ 는 후보가 줄어 F5 에 가까울 것 | 후보 24종 | **맞음** |
| P4 | 둘 다 t 2 를 못 넘을 것 | ⒜ t 0.92 | **맞음** |

**P1·P2 가 같이 틀린 것이 한 이야기다.** 나는 「양수 신호가 모인 재무 묶음이 낫고,
음수가 섞인 가격 묶음은 못 넘을 것」이라 봤다. **정반대였다** —
재무 묶음은 **겹치는 종목이 없어 아예 못 섰고**, 가격 묶음은 **음수를 둘이나 안고도
부분을 전부 넘었다.**

> **결합의 값은 「좋은 신호를 모으는 것」이 아니라 「서로 다른 실수를 하는 신호를
> 겹치는 종목에서 모으는 것」에서 온다.**
> 재무 신호들은 방향이 같아도 **같은 종목을 안 덮어 모을 수가 없었다.**

## 4. 결합을 닫는다

등록서 §7-5 대로 **세 번째 묶음을 만들지 않는다.**

**두 판(COMBO·COMBO2)에서 확인된 것**

1. **여덟을 통째로 평균하면 커버 높은 축이 지배한다**(COMBO).
2. **커버를 맞추면 재무 축은 겹치는 종목이 없어 못 선다**(COMBO2 ⒝).
3. **가격 축 셋은 결합이 부분을 넘지만 가중치를 고른 값은 0 이다**(COMBO2 ⒜ · 백분위 89).

## 5. 남는 것 — **하나는 진짜로 남는다**

### ⒜ 가격 결합은 「규칙」이 아니라 「기본값」으로 남길 만하다

결합 +0.252%/월(연 **+3.1%**) · t 0.92 · 후보 463종 · **세 축 전부 커버 99%+**.
단독 게시는 못 한다(t 0.92 · 다중검정 문턱은 말할 것도 없다).

**그런데 F3 이 말한 「어떻게 섞어도 비슷하다」는 운용에서는 장점이다** —
가중치를 맞출 필요가 없다는 뜻이다. **우량성장 30 의 분기 재구성 때
「가격 축 셋의 동일가중 z 가 하위인 종목을 그 분기만 미룬다」** 는 형태로
쓸 수 있는지는 **별도 등록**으로 물어야 한다.
⚠ 그 등록은 오늘 나온 문턱을 넘어야 한다 — **종목을 빼는 비용 연 −0.80%p**(QGMAX).
