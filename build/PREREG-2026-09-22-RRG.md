# 사전등록 — RRG 4분면이 팩터 로테이션을 가르나 · 2026-09-22

사용자 지시 2026-09-22: 「rrg 4분면으로 팩터 로테이션」.

🚨 **이 문서는 계산 전에 커밋한다.** 아래 실패 조건·예상은 결과를 보기 전에 못박은 것이고,
  돌린 뒤에 고치지 않는다. 고쳐야 할 일이 생기면 그 사실을 결과 문서에 적는다.

---

## 0. 무엇을 묻나

RRG(Relative Rotation Graph)는 상대강도를 **수준**(RS-Ratio)과 **기울기**(RS-Momentum)
두 축으로 놓고 4분면을 만든다. 그림의 전제는 둘이다 —

1. **주도(Leading) 사분면에 있는 것이 부진(Lagging) 사분면에 있는 것보다 낫다.**
2. **회복 → 주도 → 약화 → 부진 → 회복** 으로 **시계 방향** 회전한다.

둘 다 이 랩 자료로 잴 수 있다. 그래서 잰다.

⚠ 이 랩은 국면 조건부 규칙을 **12번 시도해 11번 기각**했고, 유사일 검색은 안 섰고
  (0.55/5 vs 기준선 0.75/5), 종합 Risk-On/Off 밴드는 **거꾸로** 갔고, 어제 그 밴드에
  추세축을 더한 15칸도 역방향이 안 풀려 「측정만」으로 끝났다.
  **이 등록도 기각으로 끝날 가능성이 높다는 사실을 미리 적어 둔다.**

## 1. 설계 — 계산 전에 고정

| 항목 | 값 | 왜 이 값인가 |
|---|---|---|
| 모집단 | **110종** (`src`=종목 전략 · `role`=수익엔진 · 월 계열 100개월 이상) | 이미 게시된 팩터 엔진 전부. 여기서 더하거나 빼지 않는다 |
| 자료 | `data/strategy_charts.json` 의 `charts[sid].monthly[].r` | 이미 구운 것. **여기서 백테스트를 다시 돌리지 않는다** |
| **벤치** | **`idx_monthly["S&P 500"]` 하나** | 🚨 전략마다 자기 벤치(`b`)가 달라 그대로 쓰면 4분면이 서로 비교가 안 된다. 하나로 통일한다 |
| 창 | 2016-09 ~ **2026-08** | 2026-09 는 부분 달(18일까지)이라 **뺀다** |
| 되돌아보기 | **n = 12개월** | 월 자료의 표준 눈금. 다른 값을 시도하지 않는다 |
| RS | 상대 NAV = 팩터 누적 ÷ 벤치 누적, 100 기준 | |
| **RS-Ratio** | `100 + (RS − SMA₁₂(RS)) / SD₁₂(RS)` | |
| **RS-Mom** | `100 + (M − SMA₁₂(M)) / SD₁₂(M)`, `M = RS-Ratio 1개월 차분` | |
| 사분면 | 주도(≥100,≥100) · 약화(≥100,<100) · 부진(<100,<100) · 회복(<100,≥100) | |

🚨 **되돌아보기(12)도 컷(100)도 안 움직인다.** 움직여 더 나은 4분면을 찾는 일은
  2026-08-29 에 폐기한 `nsel` 과 같은 자유도다. 그 자유도의 값은 이미 측정돼 있다 —
  **33종에서 샤프 중앙 −0.114 · t 중앙 −0.62**(PREREG-2026-08-29-ASWRITTEN-RESULT §1-2).
🚨 **RRG 산식을 여러 판으로 시도하지 않는다.** 공개된 구현마다 정규화가 다른데,
  위 한 판만 쓰고 그대로 적는다. 다른 판이 더 좋게 나오는지 보지 않는다.

## 2. 미리 적어 두는 실패 조건

돌리기 전에 못박는다. 하나라도 걸리면 그 항목은 **기각**이고, 되돌리지 않는다.

- **F1** 주도 사분면의 **다음 달 초과**(팩터 − S&P) 평균이 부진 사분면보다 **크지 않으면**
  기각. RRG 가 파는 첫째 전제가 정확히 이것이다.
- **F2** 그 차이의 t 가 **1.5 미만**이면 「구별 불가」로 적는다.
  ⚠ 1.5 는 이 랩이 다른 등록에서 쓴 값과 같다(A1FIX·RATE2·DURSTYLE4·TWOHEADS·REGIMEGRID §F2).
  결과를 보고 정한 값이 아니다.
- **F3** 🚨 **시계 방향 회전이 산식이 강제하는 것보다 많지 않으면** 둘째 전제를 기각한다.
  ⚠ 여기가 이 등록의 함정이다 — **RS-Mom 은 RS-Ratio 의 차분이므로 시계 방향은
    어느 정도 구성상 강제된다.** 그러니 「시계 방향이 반시계보다 많다」는 사실 자체는
    **아무 증거가 아니다.** 대조군을 쓴다 — 각 팩터의 월수익을 **뒤섞어**(창 안에서 셔플)
    같은 산식으로 RRG 를 다시 만들고, 그 귀무분포의 시계 방향 비율과 견준다.
    실제가 귀무 분포의 **95 백분위를 못 넘으면** 기각. 셔플 **200회**로 고정한다.
- **F4** 사분면당 관측(팩터·달 쌍)이 **500 미만**인 칸이 하나라도 있으면 **측정 불가**.
- **F5** 🚨 **관측이 독립이 아니다.** 같은 달의 110개 팩터는 같은 시장을 타므로
  (팩터·달) 쌍을 독립으로 세면 t 가 부푼다. 그래서 **달 단위로 묶어** 다시 잰다 —
  각 달에서 「주도 평균 − 부진 평균」 하나를 관측으로 삼아 t 를 낸다(관측 ≈ 108개).
  두 판정이 **갈리면 「보류」** 로 적는다. 묶지 않은 t 만 보고 통과를 선언하지 않는다.

## 3. 미리 적어 두는 예상 (맞았는지 채점한다)

1. **F1 은 통과하되 얇을 것이다.** 팩터 수준에도 모멘텀이 있다면 주도가 부진을 이겨야 한다.
2. **F2 는 걸릴 것이다.** F5 로 달 단위로 묶으면 관측이 11,880 에서 108 로 줄어 t 가 크게 준다.
3. **F3 은 걸릴 것으로 본다.** 실제 시계 방향 비율이 셔플 귀무보다 **높긴 하되 95 백분위는
   못 넘을** 것으로 본다 — 회전의 대부분이 산식의 성질이라고 보기 때문이다.
4. **지금(2026-08 기준) 가장 많은 팩터가 「부진」에 있을 것이다.** 시장 폭이 7.4/100 이고
   시총가중이 동일가중을 1개월 3.7%p 앞서는데, 이 110종은 대부분 동일가중 10~50종목이라
   S&P 에 지고 있을 것이다.

## 4. 무엇을 하지 않나

- 🚨 **이 4분면으로 전략을 만들지 않는다.** 「주도 사분면 팩터를 사라」 는 이 등록의
  산출물이 아니다. 그것을 하려면 **별도 등록**이 필요하다.
- 되돌아보기(12개월)·컷(100)·RRG 산식 판을 움직여 더 나은 그림을 찾는 일.
- 모집단을 「잘 도는 팩터」로 다시 자르는 일.
- 부분 달(2026-09)을 검정에 넣는 일. **현재 위치 표시에만** 쓸지는 결과 문서에 적는다.

## 5. 판정 어휘

이 랩의 넷만 쓴다 — **기각 · 게시 · 측정만 · 보류**.
「성과 개선」은 판정이 아니다.

⚠ 통과해도 나오는 것은 **팩터 위치 그림**이지 초과성과 주장이 아니다.
