## 0. 원문과 왜 이것인가

- **원문**: Medhat, M. & Schmeling, M. (2022). «Short-term Momentum». *The Review of Financial Studies* 35(3), 1480–1526.
  CQA(Chicago Quantitative Alliance) 학술경진 2018 1위. 수용본을 직접 열어 읽었다
  (City, University of London 공개본 MS_short_term_mom_v27).
- **주장**: 지난달 수익률의 효과가 **지난달 회전율에 따라 방향이 갈린다.** 회전율이 높은 종목은
  지난달 흐름이 **이어지고**(STMOM), 낮은 종목은 **되돌린다**(STREV*). 대형주에서는 되돌림이 사라지고
  이어짐만 남는다.
- **원문 수치(1963-07~2018-12, 금융업 제외, 시총가중)** — 표 III 패널 C(시총 상위 500종목, 지난달 수익률과
  회전율을 각각 250위에서 가르는 2×2 독립 정렬): STMOM **월 0.42% (t 4.91)** · FF6 알파 0.43 (t 4.99) ·
  STREV* **−0.02% (t −0.19)**. 메가캡·형성월 마지막 3일 제외판은 비용 뒤 월 0.59% (t 3.10)(표 VII).
- **랩 기준을 넘는 이유**: [조건] 회전율이 수익률 신호의 부호를 바꾼다(단일 정렬이 아니다) · [구성] 시총가중 ·
  [회전] 형성월 끝 며칠을 건너뛰는 판과 비용 차감이 원문에 있다. 2020년 이후 RFS 게재.
- **랩에서 새로운 것**: 랩에는 «단기 반전(1개월 최하위 10)» · «저회전율 최하위 10» 이 **따로** 게시돼 있다.
  둘을 **조건으로 엮은** 규칙은 없다. 그리고 이 논문은 대형주에서 단기 반전 다리가 **0** 이라고 말한다 —
  랩의 게시 규칙과 정면으로 맞서는 검정이다.
- 🚨 **발표 후 표본이 공짜로 생긴다.** 원문 표본은 2018-12 에 끝난다. 랩의 2019-01 ~ 2026-08 은 원문이
  보지 못한 92개월이다.

## 1. 설계 — 계산 전에 고정

| 항목 | 값 | 근거 |
|---|---|---|
| 창 | 형성 2016-08 ~ 2026-07 · **보유 2016-09 ~ 2026-08 (120개월)** | 랩 PIT 전략 계열과 같은 창(strategy_charts.json) |
| 발표 후 창 | 보유 **2019-01 ~ 2026-08 (92개월)** | 원문 표본 끝 2018-12 다음 달부터 |
| 모집단 | 형성월 말 **그때의** S&P 500 ∪ NASDAQ 100 멤버(`index_members.load`) | 시점정확. 원문 «상위 500» 의 대응물 |
| 제외 | **금융업**(GICS Financials) — 원문과 같다 · 이중클래스는 회사당 하나(GOOGL·FOXA·NWSA 를 남긴다, DATA-FACTS §5) | |
| 가격 | 오늘 유니버스 `data/sd/*.json` pxd · 편출 `data/_pit_px_cache.json`. 옛 티커는 `pit_universe.json` 의 `cik_spliced` 로 잇는다 | 새로 받지 않는다 |
| 거래량 | `sd` vd · 편출 `_pit_vol_cache.json` | |
| 주식수 | 랩 정본 `tech_backtest.load_fund()`(편출 `data/fx_pit` 포함)의 `sh`, 형성일 기준 `asof_all`(랩 공시 지연 그대로) | 저회전율 규칙 x-turn 과 같은 분모 |
| 신호 | **r** = 형성월 수익률(전월말→형성월말) · **TO** = 형성월 일간 거래량 합 ÷ 주식수 | 원문 r1,0 · TO1,0 |
| 자격 | 형성월에 유효한 일간 수익·거래량 **15일 이상** · 형성월말 가격·주식수 있음 | 원문(표 VI 절)의 15일 규칙 |
| 정렬 | r 과 TO 를 **각각 중앙값에서** 가르는 2×2 **독립** 정렬 | 원문 표 III 패널 C(500종의 250위 = 중앙값) |
| 비중 | **시총가중**(형성월말 가격 × 주식수), 월말 재조정 | 원문 |
| **STMOM (판정)** | 고회전·승자 − 고회전·패자 | 원문 |
| STREV* (서술) | 저회전·승자 − 저회전·패자 | 원문 |
| 보유월 수익 | 형성월말 → 다음 달 말 배당조정 종가. 달 중간에 가격이 끊기면 마지막 가격에서 나온다(그 뒤 0) | |
| 비용(F5) | 편도 **10bp** × 원문 식(1)의 회전 — 두 다리 각각 | 원문 메가캡 반스프레드 7~8bp 보다 보수적으로 |

⚠ **알고 있는 편향** — 계산 전에 적는다.
- 가격이 배당조정이라 과거 시총이 배당만큼 작게 잡힌다(고배당주 비중이 과거로 갈수록 조금 줄어든다). 무게에만 영향.
- 편출 종목 중 가격이 없는 것(주로 인수)은 빠진다 — 랩 PIT 커버리지 문제 그대로다. 월별 커버리지를 싣는다.
- 회전율은 미국 상장분 거래량 ÷ 회사 전체 주식수라 이중클래스·외국 발행인이 **낮은 회전** 쪽으로 밀린다
  (DATA-FACTS §7). STMOM 은 **고회전 절반만** 쓰므로 그 종목들은 대부분 판정 다리에서 빠진다 — 오염이
  STMOM 을 부풀리는 방향은 아니다. STREV* 다리에는 섞인다(서술만 하는 이유 중 하나).

## 2. 실패 조건 (하나라도 걸리면 그 판정)

- **F1** STMOM 120개월 평균 ≤ 0 → **기각**.
- **F2** 그 t < **1.5** → 구별 불가 → **기각**(SECEW·SECRRG 와 같은 매핑). ⚠ 원문과 같은 샤프라면 120개월에서 기대 t ≈ 4.91×√(120/666) ≈ 2.1 이다.
- **F3** 🚨 **발표 후 92개월(2019-01~)** STMOM 평균 ≤ 0 → **기각**(발표 뒤 사라졌다).
- **F4** 월별 가격 커버리지(자격 판정 전 멤버 중 가격이 있는 비율) 최저 < **80%** → **보류**(랩 PIT 바닥과 같은 수).
- **F5** 편도 10bp 뒤 평균 ≤ 0 → **기각**(못 쓰는 규칙).
- **F6** 🚨 **증분**: 랩 종목 수익엔진 110종(PREREG-2026-09-22-RRG 와 같은 모집단 — `src`=종목 전략 · `role`=수익엔진 · 100개월 이상)의
  월 초과(r − b) 중 STMOM 과 |상관|이 가장 큰 **5종**을 동시에 통제한 알파의 t < **1.5** → **보류**(«이미 랩에 있는 베팅»).

판정 매핑: F1·F2·F3·F5 → 기각 · F4·F6 → 보류 · 전부 통과 → **게시 후보**(곧바로 게시하지 않는다 — §4).

## 3. 미리 적는 예상 (채점한다)

1. **STMOM 은 양수이되 원문보다 약하다** — 월 0.1~0.3%, t 는 1.5 근처. F2 를 넘을지는 반반으로 본다.
2. **STREV* 는 0 근처**(|월 평균| < 0.2%) — 원문 대형주 결과와 같다. 랩의 «단기 반전» 게시 규칙과 어긋나는 증거가 된다.
3. **발표 후(F3)가 더 약하다** — 발표 뒤 감쇠(평균 이상현상 기준 절반 안팎)를 예상한다. 부호는 양수로 본다.
4. **회전은 다리당 월 80% 이상**(원문 83~91%).

## 4. 하지 않는 것

- 형성월 마지막 3일을 건너뛰는 판(원문 표 VI·VII)은 **서술로만** 싣는다. 판정은 표 III 패널 C 그대로 한 판.
- 정렬 기준(중앙값)·창·비용·모집단을 바꿔 다시 보지 않는다.
- 통과해도 곧바로 게시하지 않는다. 게시는 랩 PIT 엔진에 규칙을 등록해 같은 잣대(PIT 레그·incr5·밴드)로 다시 재는 **다음 단계**다.
- 롱온리 판(고회전 승자 다리 vs 모집단 시총가중)은 **서술**로만 싣는다 — 지수 펀드 틸트로 쓸 때의 모양을 보려는 것이다.
