## 0. 원문과 왜 이것인가

- **원문**: Hou, K., Mo, H., Xue, C. & Zhang, L. (2021). «An Augmented q-Factor Model with Expected Growth».
  *Review of Finance* 25(1), 1–41. 원문 PDF(theinvestmentcapm.com q5rf2021)를 직접 열어 산식을 읽었다.
- **방법(원문 3.1절)** — 여러 단계가 원문에 있다:
  - [신호] 1년 뒤 투자/자산 변화 E_t[d1 I/A]
  - [결합] 매월 **시총가중 WLS 횡단면 회귀**로 log(토빈 q) · 현금기준 영업수익성 Cop · ΔROE(dRoe) 세 예측변수를 한 예측치로 합친다. 좌우변 1–99% 윈저.
  - [적응] 기울기는 **직전 120개월 회귀 기울기의 평균**(최소 30개월). 회귀의 종속변수는 이미 실현된 d1 I/A, 설명변수는 그보다 12개월 앞선 값.
  - [구성] 크기 × Eg 정렬, 시총가중.
- **발표 전·후 증거(공개 자료 global-q.org 2025판으로 이 랩이 직접 재계산)** — 대형(NYSE 중앙 이상) 고Eg − 저Eg, 시총가중:
  2006–2025 월 +0.48% (t 2.34) · 2019–2025 +0.49% (t 1.10) · 랩 창 2016-09~2025-12 +0.74% (t 2.06).
  롱 다리(대형 고Eg − 대형 평균): 2006–2025 +0.31% (t 2.81) · 2019–2025 +0.45% (t 1.74).
- **왜 이것인가**: 이 조사의 냉정한 배경 — Chen·Welch(2026, arXiv 2607.06502 «What Useful Alphas?»)는 2006년 이후 비미소형주에서
  발표된 이상현상 수익의 중위값이 **월 7bp** 라고 보고한다. 그 속에서 Eg 는 대형주·발표 후에도 부호가 살아 있는 드문 축이고,
  랩에는 «미래 투자 증가 예측» 축이 없다(자산성장 회피는 **현재** 투자이고 부호도 반대다).

## 1. 🚨 원문과 다른 자리 — 계산 전에 적는다

| 원문 | 이 등록 | 왜 |
|---|---|---|
| Cop = 매출 − 매출원가 − 판관비 + R&D − Δ매출채권 − Δ재고 − Δ선급비용 + Δ이연수익 + Δ매입채무 + Δ미지급비용, ÷ 총자산 | **Cop ≈ 영업현금흐름(cfo, 연간) ÷ 총자산** | 판관비·R&D·매출채권·재고·선급·이연수익·매입채무·미지급이 랩에 없다. 영업현금흐름은 같은 «현금기준» 을 재는 가장 가까운 태그다. ⚠ 원문은 결과가 Cop 에 크게 기댄다고 적었다 — 이 대체가 이 등록의 최대 위험이다 |
| dRoe 는 실적 발표일(RDQ) 기준 최신 분기 | 분기말이 **90일 이상 지난** 최신 분기(랩 공시 지연 FUND_LAG_DAYS 그대로) | 과거 발표일 이력이 없다 |
| 회귀 표본 = CRSP 전 종목 | **랩이 재무를 가진 전 종목**(오늘 518 + 편출 `fx_pit` 145, 금융·음(−)자본 제외) | 기울기는 회계 관계(투자 ~ q·현금흐름·dRoe)라 생존편향의 영향이 수익률보다 작다고 본다 |
| NYSE 기준 크기 2 × Eg 3 정렬 | 모집단이 전부 대형주라 **Eg 3분위(30/70)만** · 판정 = 고Eg − 저Eg 시총가중 | 공개 자료의 «대형 고 − 대형 저» 와 같은 비교 |

## 2. 설계 — 계산 전에 고정

| 항목 | 값 |
|---|---|
| 창 | 형성 2016-08 ~ 2026-07 · **보유 2016-09 ~ 2026-08 (120개월)** — 단기 모멘텀 등록과 같다 |
| 발표 후 창 | 보유 **2019-01 ~ 2026-08**(원문 표본 끝 2018-12 다음) |
| 모집단(포트폴리오) | 형성월 말 그때의 S&P 500 ∪ NASDAQ 100 멤버 · 금융 제외 · 음(−) 자본 제외 · 이중클래스 회사당 하나(STMOM 과 같은 규칙) |
| 재무 시점 | «가장 최근의, 4개월 이상 지난 회계연도말»(원문) — 연간 흐름 태그(cfo·ni)의 연간 버킷 날짜로 회계연도말을 정한다 |
| log q | log((시가총액 + debt) ÷ 총자산), 회계연도말 기준. debt 가 없으면 0 |
| I/A | 회계연도말 총자산 ÷ 1년 전 회계연도말 총자산 − 1 |
| 종속변수(회귀) | 형성월 t 에 알려진 I/A − 12개월 전(t−12)에 알려져 있던 I/A |
| 설명변수(회귀) | t−12 시점의 log q · Cop · dRoe (원문처럼 12개월 더 뒤로) |
| 회귀 | 월별 시총가중 WLS, 좌우변 1–99% 윈저, 기울기 = 직전 120개월 평균(최소 30개월) |
| 예측 E_t | t 시점 예측변수(윈저) × 평균 기울기 |
| 정렬·비중 | 형성월 말 E_t 3분위(30/70) · 시총가중 · 다음 달 한 달 보유 |
| 비용(F6) | 편도 10bp × ½Σ\|Δw\| (두 다리 각각) |

## 3. 실패 조건

- **F1** 고Eg − 저Eg 120개월 평균 ≤ 0 → **기각**.
- **F2** 그 t < **1.5** → **기각**(구별 불가 · SECEW 매핑).
- **F3** 발표 후(보유 2019-01~) 평균 ≤ 0 → **기각**.
- **F4** 🚨 **예측 단계 점검** — E_t 와 그 뒤 실현된 d1 I/A(12개월 뒤에 알려진 I/A − 지금 I/A)의 **월별 횡단면 순위상관 평균 ≤ 0** 이면 **기각**
  (Cop 대체로 예측기가 망가졌다는 뜻 — 그러면 수익 결과는 Eg 의 검정이 아니다). 원문 1년 지평 순위상관은 표 I 패널 D 참조.
- **F5** 랩 종목 수익엔진 110종 중 |상관| 상위 5종 동시 통제 알파 t < **1.5** → **보류**(«이미 랩에 있는 베팅»).
- **F6** 편도 10bp 뒤 평균 ≤ 0 → **기각**.

판정 매핑: F1·F2·F3·F4·F6 → 기각 · F5 → 보류 · 전부 통과 → **게시 후보**(곧바로 게시하지 않는다).

## 4. 미리 적는 예상 (채점한다)

1. **F4 는 통과한다** — 순위상관 0.05~0.20. q·현금흐름·dRoe 가 투자 변화를 맞히는 것은 회계 관계라 대체 변수로도 선다고 본다.
2. **스프레드는 양수이되 t 는 1.5 미만** — 월 0.1~0.4%. 대체 Cop 와 좁은 모집단(약 430종 vs CRSP 대형 절반)이 공개 자료(+0.74%, t 2.06)를 깎는다. → **F2 에서 기각**을 예상한다.
3. **발표 후는 양수**다.
4. **F5 에서 상관 상위는 퀄리티·수익성 계열**(이익 품질 · 자산성장 회피 등)일 것이다.

## 5. 하지 않는 것

- Cop 를 다른 대체식(영업이익 + 감가상각 등)으로 «한 번 더» 보지 않는다. cfo ÷ 자산 한 판.
- 2년·3년 지평 Eg, 분위 기준·창·가중을 바꾸지 않는다.
- 롱온리(고Eg − 모집단)는 서술로만 싣는다.
