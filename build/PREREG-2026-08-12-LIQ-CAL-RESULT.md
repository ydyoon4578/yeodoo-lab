## 2. 🚨 이 배치의 진짜 소득 — 게시 관문에 구멍이 있었다

`x-amihud` 는 처음에 **`통과 후보`** 배지를 달고 나왔다. 이 랩의 첫 통과 후보였다.
그런데 PIT 레그가 비어 있었고, 재판정 코드를 보니:

```python
m = PIT_MEASURED.get(r["sid"])
if not m:
    continue                      # ← PIT 이 없으면 그냥 넘어간다
if r["verdict"] == "통과 후보" and abs(pt) < tcrit:
    r["verdict"] = "구별 불가"     # ← 재서 진 규칙만 강등된다
```

**재서 진 규칙은 강등되고, 아예 못 잰 규칙은 통과한다.** 정확히 거꾸로다 —
'못 쟀다'는 '모른다'이고, 이 계열의 알려진 사전확률은 강하게 부정적이기 때문이다.

### 그 사전확률이 얼마나 센가 — `x-small` 실측

`x-amihud` 의 **1순위 이웃이 `x-small`(소형주)** 이다(등록 §2① 에서 그렇게 될 것이라 미리 적었다).
그 규칙은 PIT 레그가 있다:

| | 소급(오늘의 518종을 과거로) | 시점정확(PIT) |
|---|---|---|
| CAGR | 53.09 | 11.37 |
| 초과 CAGR | +40.41 | **+1.69** |
| **t** | **6.97** | **0.52** |

`bias_excess` = **+49.67%p**. 생존편향 하나가 초과수익을 50%p 만들어 냈다.
`x-amihud` 의 소급 t 6.84 는 `x-small` 의 6.97 과 거의 같은 자리에 있다.

### 왜 PIT 을 못 재나 — `x-volsurge` 와 **같은 벽**

`build/pit_backtest.py` 는 `x-volsurge` 를 이미 제외해 두었다:

> 거래량이 랩 파일(오늘의 유니버스)에만 있어 편출 85종의 채점률이 정확히 0%다 — 후보가
> 100% 생존자인 채로 편출종목을 포함한 대조군과 겨루게 되어, 이 파일이 없애려는 바로 그
> 선견이 규칙 하나에만 남는다.

`x-amihud` 의 분모가 **거래대금**이고 `x-turn` 의 분자가 **거래량**이다. 같은 벽이다.
⚠ 등록할 때 이 제약을 못 봤다. 후보 밀도는 월별로 쟀으면서(1차의 교훈) **PIT 가능 여부는
  안 쟀다.** 프로브 항목이 하나 더 필요했다.

## 4. 나머지 둘

**`x-turn` 저회전율 — 기각.** t 1.43 · incr5.t 1.26. 이웃 5개가 전부 저변동성·복권형 회피
계열이었다(`x-lowvol-n100`·`x-max5low-n52`·`x-maxlow-n52`·`x-max5low`·`x-lowvol`).
즉 **회전율은 이 표본에서 저변동성의 다른 이름**이었다. 등록 §2② 가 물은 것
("①과 같은 결과면 자가 결과를 만든 게 아니다")에 대한 답: 둘은 **갈렸다** —
`x-amihud` 의 이웃은 규모·가치였고 `x-turn` 의 이웃은 변동성이다. 같은 '유동성'이라는
말을 붙였지만 두 자는 다른 것을 재고 있었다.

**`t-tom` 월말 효과 — 열위.** CAGR 5.19 · 초과 −7.00 · t −1.98 ·
`vs_traded` 초과 −13.58(t −3.36) · 노출 19.1% · 회전율 24.1배.

등록 §2③ 에서 **미리** 이렇게 적었다: "노출 19% 로 매수후보유를 따라잡기만 해도 원논문
주장이 재현된 것이고, 초과 CAGR 0 근처는 실패가 아니다."
→ 실측은 0 근처가 아니라 **−13.58%p** 다. 이 표본(2010-01~2026-08)에서
McConnell·Xu(2008)의 주장은 **재현되지 않았다.** 4일 창은 나머지 날의 수익을 대체하지 못한다.
⚠ 회전율 24.1배는 이 랩 최고 수준이다 — 무비용 기준인데도 졌으므로 비용을 태우면 더 진다.
⚠ 이 결과가 원논문을 반박하지는 않는다. 원논문 창은 1926~2005 이고 이 표본은 2010~2026 이다.
  달력 효과는 널리 알려진 뒤 사라진다는 보고가 많다(Marquering et al. 2006).
