## 2. L1 규칙 (`build/lib_meta.py`)

- **구성**: U_LIB 가족 + SPY(능동 0). 결정마다 준복제를 거른다 — (뗀 접미사 수, sid) 순으로 훑으며 이미 남긴 가족 모두와 W_t 순 능동(x = r − cost_drag/12 − SPY TR)의
  |ρ| ≤ 0.95 인 가족만 남긴다(탐욕 — 빠진 가족과의 상관은 보지 않는다).
- **달력**: 분기말 t(3·6·9·12월 말) · W_t = 2016-10 부터 쓸 수 있는 달 중 최근 min(60, 가용) · 36개월 이상 · 첫 결정 2019-09 · U_t = W_t 전 달에 x 가 있는 가족.
- **추정(둘째 모멘트만)**: 가족마다 x = a + c⁺·s⁺ + c⁻·s⁻ + e(s = SPY TR · s⁺ = max(s, 0) · s⁻ = min(s, 0) · 고전 공분산).
  L = (c⁺ + c⁻)/2 · Δ = c⁺ − c⁻ · 표준오차는 계수 공분산에서. L · Δ 를 따로 동일가중 횡단면 평균 쪽으로 EB 축소(τ² = max(0, 횡단 분산 − 평균 SE²) · B = SE²/(SE² + τ²)).
  c̃⁺ = L̃ + Δ̃/2 · c̃⁻ = L̃ − Δ̃/2. **절편 a 는 쓰지 않는다**(ã ≡ 0).
- **시나리오(지수만)**: 2006-02 ~ t SPY TR · σ_pre 로 가른다 — S_S = 급등월 평균 · S_C = 급락월 평균 · 평상월 s⁺ · s⁻ 평균.
  기대 능동: 급등 A^S = c̃⁺ S_S · 급락 A^C = c̃⁻ S_C · 평상 A^N = c̃⁺ S̄⁺ + c̃⁻ S̄⁻ · SPY 는 모두 0.
- **선형계획(보유 h)**: h_SPY ≥ ½ · 가족마다 0 ≤ h_i ≤ 2% · Σh = 1 · 최대화 z − κ Σ|h − h^d|, 제약 z ≤ Σ h A^S · z ≤ Σ h A^C ·
  평상 바닥 Σ h A^N ≥ Σ n A^N · 일관성 천장 (1/|W|) Σ_m max(0, −Σ h x̃_m) ≤ n 의 같은 값(x̃ = W_t 안에서 평균을 뺀 x · 알파 없는 반절대편차).
  n = ½ SPY + ½ C1_t(순진한 절반 지수 섞기 · 늘 가능). κ = 0.10/3 %/월(편도 10bp 를 3개월 보유로). h^d = 직전 h 를 t 까지 드리프트(U 밖으로 나간 몫은 SPY).
  첫 표본 안 결정과 첫 전방 결정은 h^d = n · κ = 0. 동률은 목적값을 지키며(허용 1e-7 × (1 + |최적값|)) Σ|h − h^d| 를 최소로 하는 두 번째 선형계획으로 깬다.
  풀이: scipy 1.18.1 HiGHS 기본(30초 제한) — 시간 한도에 걸리면 내부점법(크로스오버)으로 다시 푼다(대체 횟수를 산출물에 적는다 · --dry 에서 3회).
  다른 scipy 판에서는 돌지 않는다(꼭짓점 선택이 판마다 다를 수 있다). 동률 깨기가 실패하면 멈춘다.
- **보유**: 분기 안 드리프트 · 결정 다음 달에 편도 10bp × Σ|h_new − h_drift| · 계열이 끊기면 그달은 SPY 로 보고 달말에 SPY 로 옮긴다(판 다리 + 산 다리 = 2 × 10bp × 그 몫).
- 그 밖에 추정하는 것은 없다. sid 목록 · cost_drag · 씨앗은 등록 때 얼린다.

## 3. 대조군 · 위약

- **C1** 같은 유니버스 1/N(분기 · 드리프트 · 같은 비용 · 100% 라이브러리) · **C2 주 대조군** β 를 맞춘 1/N — 매달 C1 을 SPY(β 를 올릴 때) 또는 T-bill(내릴 때)로 채워
  규칙의 직전 36개월 실현 β(12개월 미만이면 결정 때의 사전 β = 1 + Σ h L̂)에 맞춘다. β(C1) = C1 의 직전 36개월 OLS β(12개월 미만이면 1 + 평균 L̂).
  규칙 β > 1 이면 C2 = SPY(표시). 세 다리(C1 · SPY · T-bill) 비중의 드리프트 뒤 Σ|Δw| 에 편도 10bp.
- **K4** 실현된 분기 목표 순서를 1000번 섞는다(씨앗 20260814 · 목표 분기 U 밖 sid 는 SPY 로) — Ψ_M 과 mean(규칙 − C2) 의 백분위.
  섞인 경로마다 C2 를 그 경로 자신의 β(사전 β 는 섞인 목표 × 그 분기 L̂)로 다시 맞춘다.
- **P4 대칭 쌍둥이**: 같은 선형계획에 Δ̃ ≡ 0 — 비대칭 정보만 떼어 본다. **P5 성과 추종**: 두 시나리오 제약 대신 z ≤ Σ h ã — ã = x 를 [1, s] 에 단순 회귀한 절편
  (무조건부 알파 · 고전 SE)의 EB 축소(§2 의 조건부 절편 a 가 아니다) — LOWCORR 식 실패 모양.
- **P6 노출 정적**: (1 − q̄)·SPY + q̄·T-bill · q̄ = 결정마다 타이밍류(타이밍오버레이 · 배분기 · 위험방어) Σ h_i(1 − β̂_i) 의 평균.
- **P7 요인 증분**: §1 T6.
- 보고만(문턱 없음): 펀드 틀(S&P 90% + 10% L1) · L1-α(알파 포함판) 등 쌍둥이는 이 등록에서 계산하지 않는다(뒤 등록 때 서술로).

## 4. F0 점검 (등록 커밋 뒤 가장 먼저 · 비중·베타만 · 규칙 수익 없음 → `data/_libmeta_L1_f0.json`)

- F0a 시간 평균 능동 비중 ½Σ|h − SPY| < 0.10 → 지수와 구별 안 됨 · 시작하지 않는다.
- F0b w* 상위 20 명단이 바뀐 결정 ≤ 6 → 측정 불가. 명단 = 보유(> 0) 가족 중 20번째 비중 이상 전부(동률 모두 · 1e-9 허용 · 20 미만이면 보유 전부).
- F0c |U_t| 중앙 < 30 → 유니버스가 얇다 · 시작하지 않는다.
- F0d 평균 ½Σ|w*_L1 − w*_P5| < 0.3 → «성과 추종» 라벨(그래도 돈다).
- F0e 결정 때 Δ̃ 와 다음 겹치지 않는 12개월 OLS Δ̂(라이브러리 가족 수익만)의 스피어만 IC(동률은 평균 순위) 평균 ≤ 0 → «β 맞추기, 볼록성 정보 없음» 라벨 —
  볼록성 전략으로 전방 시계를 켜지 않는다(H1 자리는 둔다). EB 가 Δ̃ 를 상수로 줄인 결정(τ²_Δ = 0 · 그 결정의 L1 에는 비대칭 정보가 없다)은 IC 0 으로 세고 그 수를 적는다.
- F0f w* 의 타이밍류 비중 시간 평균 > 40% → «시장 타이밍 재포장» 라벨 — 게시에 P6 을 이기는 조건을 더한다.
- F0 도 등록 커밋 뒤에만 돈다(`LIBMETA_COMMIT` 필요 · 커밋을 파일에 적는다). 그다음에야 표본 안 오염 측정(§1 지표 전부 · 대조군 · K4)을 돌린다 →
  `data/_libmeta_L1.json` — 같은 커밋의 F0 파일이 먼저 있고 다시 셈한 F0 와 같아야 돈다. 표본 안의 어떤 수도 판정하지 않는다.
