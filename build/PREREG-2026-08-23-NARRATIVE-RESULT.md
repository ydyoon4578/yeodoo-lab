## A1 — 전환이 두 다리 각각보다 나쁘다

사전등록이 못박은 잣대는 «전환이 두 다리 각각보다 나은가» 였다.

    x-realsw (전환)  샤프 0.883
    x-fcfy   (단독)  샤프 1.004   ← 전환보다 좋다
    x-rgrow  (단독)  샤프 0.909   ← 전환보다 좋다

등록 문서의 문장 그대로다 — «단독보다 못하면 국면을 잘못 읽었다는 뜻이다».
실질금리 z 로 두 축을 갈아타는 것은 **그냥 잉여현금흐름을 계속 들고 있는 것보다 못했다.**
전환 자체가 비용이다(회전율 2.37 vs 단독 1.21·1.05).

## 🚨 이 실행에서 잡은 버그 둘 — 사전등록의 실패 조건이 잡았다

등록 문서에 «게이트가 켜진 달 수를 싣는다» 를 미리 적어 둔 것이 두 번 일했다.

**① 게이트가 한 번도 안 꺼졌다.** 1차 실행에서 A2·C2 의 무보유월이 **0** 이었다.
  원인 — 바스켓 전수 시험이 만드는 변형 sid(`x-fxweak-n20`)가 상태 함수의 이름 비교에
  안 걸려, 변형은 게이트를 **한 번도 안 타고** 돌았다. 즉 «국면 게이트 규칙» 이라 적힌
  것이 게이트 없는 규칙이었다. 밑동 sid 로 비교하게 고쳤다(무보유 0 → 67개월).

**② «숏» 이라 적힌 규칙이 롱으로 돌았다.** ①을 고치고 다시 돌리니 C1 이 CAGR
  **+28.44** 로 나왔다. 숏 바스켓이 10년간 연 28% 씩 떨어졌다는 뜻이라 말이 안 된다.
  원인은 같은 유형 — `SHORT_SIDS` 판정도 원문 sid 로 해서 `x-ratehot-n30` 이 부호 반전을
  안 탔다. 라벨과 계산이 갈린 것이고, **성적이 좋게 나왔기 때문에 더 위험한** 종류다.
  고친 뒤 −27.94 로 돌아왔다.

⚠ 둘 다 «수치가 이상하다» 로 잡은 것이 아니라 **미리 적어 둔 실패 조건을 확인하다** 잡았다.
  실패 조건을 안 적었으면 ①은 영원히 안 보였을 것이고, ②는 좋은 성적으로 배포됐을 것이다.

  매월 갈아타면 **그 갈림을 못 따라간다** — 이미 벌어진 뒤에 사고 좁혀진 뒤에 판다.
  즉 «서브산업이 갈린다» 는 관찰은 맞고, «상대강도로 그걸 잡을 수 있다» 는 가설이 틀렸다.

  더 나빠진다. 숏 다리의 차입비용은 아예 안 물린 상태다.

## 엔진에 더한 것 (B1·B2 때문에)

· **롱숏 경로** — 기존 가중 바스켓은 Σw 로 되정규화하는데 롱숏은 Σw = 0 이라 그 식이
  0 으로 나눈다. **다리별로** 되정규화해 각 다리 합을 1 로 되돌린다(롱100/숏100).
  한쪽 다리가 통째로 결측인 날은 0 으로 둔다 — 반쪽만 들고 «중립» 이라 부르지 않는다.
· **sub_baskets()** — 서브산업 집계. 소속 3종 미만 제외, 서브산업 안에서는 시총 상위 5종만.
  ⚠ 후보를 sc 에서 받는다. X["tickers"] 를 그대로 쓰면 PIT 마스킹을 우회해 그때 지수에
    없던 종목이 집계에 들어간다(선견). 처음에 그렇게 짰다가 고쳤다.
· 바스켓 전수 시험에서 뺐다 — 선택 단위가 서브산업이라 «상위 N 종목» 이 없고, 돌리면
  같은 규칙이 세 번 세어져 다중검정 족만 부푼다.
